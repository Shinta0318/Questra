# Questra Trust & Safety Enforcement Spec V1

## 原則

- Arc ChatとQuest生成の前に同じ安全ゲートを通す。
- 重大な危害の実行支援は拒否し、安全で合法な目的への言い換えを示す。
- 被害防止、相談、教育、研究、創作などの正当な文脈を単語一致だけで拒否しない。
- 自傷の切迫した表現はQuest化せず、本人の安全と地域の緊急支援を優先する。

## 記録と制限

- `abuse_signals`にはカテゴリ、重大度、確信度、理由コード、ポリシー版、時刻だけを保存する。
- 処罰目的だけでArc会話やQuest原文を保存しない。
- 低確信度の判定だけでアカウントを永久制限しない。
- 一時制限は解除可能にし、永久制限には担当者、判断理由、異議申立て導線を必須とする。
- 管理者アクセスはService Roleと監査ログに限定し、ユーザーは自分の有効な制限だけを参照できる。

## 保持

未確認シグナルは運用開始時に保持期間を設定する。Betaでは自動永久BANを有効化せず、保持・削除・異議申立て手順が整うまでレビュー用途に限定する。

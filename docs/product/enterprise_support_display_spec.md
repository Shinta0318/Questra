# Enterprise Mission Support Display Spec V1

- 企業はユーザーへQuestを押し付けず、Mission達成を支援する。
- 役割はSponsor、Coach、Partner、Official Event Hostの4種類に限定する。
- `Arcが調べた情報`と`企業からの支援`を別見出し、別データ契約、別計測にする。
- 審査済み・有効期間内・HTTPS遷移先を持つ提案だけを表示する。
- 企業名、役割、便益、費用、条件、有効期限、提供関係、選定理由を隠さない。
- Arcは有料掲載を中立的な助言として語らず、非スポンサーの選択肢を妨げない。
- 企業へ個別Questデータを渡さない。将来必要な場合は用途ごとの明示同意を別途求める。
- Betaでは機能フラグを既定OFFとし、決済や行動ターゲティングを実装しない。

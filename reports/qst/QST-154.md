# QST-154 Home Simplification

## Summary

Homeを中心体験だけへ整理した。表示順はArc、今日やるMission、進行中Questで固定し、補助機能のカードを通常表示から外した。

## Changed Files

- `apps/mobile/lib/features/home/home_screen.dart`
- `apps/mobile/test/responsive_screen_smoke_test.dart`
- `docs/qst/BACKLOG.yaml`

- `reports/qst/QST-154.md`

## Implementation Notes

- Arcの短いメッセージと`Arcに話す`主要CTAを表示する。
- 未完了Missionを最大5件表示し、Checkboxから既存`completeMission`へ接続した。
- 進行中Questを最大3件表示し、次の未完了Missionを併記した。
- Guild、Trail、Star Map、Horizon、Signal、進行ランク、重複CTAを通常表示から外した。
- 非表示にした旧Widgetは将来再開できるよう削除せず保持した。
- DB、Route、Controller、既存ユーザーデータは変更していない。

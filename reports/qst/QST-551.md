Status: In Progress / local_web_verified; Android pending

- Date: 2026-10-08 (Asia/Tokyo)
- Branch/HEAD: `codex/initial-questra-structure-pr` / `a9d83bc`; this dirty worktree is not a release candidate.
- Origin: while verifying QST-548 at 390px, editing the login ID made the untouched password field red. The same happened to untouched account fields after entering a signup nickname. This adds avoidable pressure before the user reaches those fields.
- Design Bible alignment: first-use clarity and calm feedback, without weakening required-field validation.

## Change

Login, signup, and password-reset forms no longer set form-wide `AutovalidateMode.onUserInteraction`. Each field now validates after its own interaction, while the existing submit handlers still call `FormState.validate()` for all required fields. Single-field email forms were left unchanged. Authentication, database, email, and lockout behavior were not modified.

## Verification

- A new three-screen widget regression test failed before the change: all three untouched fields showed errors. After the change, all three passed. The login test also confirms an edited short ID shows an immediate local error, clears after correction, and submit still flags an empty password.

- The debug Web server rendered a blank page after restart even though its resources loaded. A separately built static connected preview at `http://127.0.0.1:5268/` rendered normally. Playwright/Edge at a true 390px viewport found no horizontal overflow and no untouched-field error after entering synthetic text on login and signup. Evidence: `reports/qst/evidence/QST-551/login-first-field-390.png` and `signup-first-field-390.png`.
- The Backlog SSOT verifier passes after using its supported `local_partial` evidence state; the detailed report still records the narrower Web verification above.
- No real account was created, no credential or private text was recorded, and no Hosted login success is claimed. Android IME, large text, and the password-recovery callback remain unverified. External Beta remains NO-GO for QST-547 blockers.

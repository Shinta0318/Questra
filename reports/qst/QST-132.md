# QST-132 Report: Onboarding Tour Polish

## Summary

Hardened the Arc onboarding tour introduced in QST-131. The tour can now appear
when the authenticated profile is restored after the shell is already mounted,
while the controller still prevents repeated display after dismissal in the same
session. The replay path remains available from Settings.

## Acceptance

- Profile restore changes are listened to from `AppShell`.
- `OnboardingTourController.showIfNeeded` respects profile-level seen state.
- `dismiss` marks the local session as seen and prevents repeat display.
- `replay` can show the tour after dismissal.
- `UserProfile.copyWith` preserves `hasSeenOnboardingTour`.

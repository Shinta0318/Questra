# QST-358 Privacy-Safe Runtime Evidence Adapter Report

Date: 2026-08-25  
Status: ImplementedFoundation

## Outcome

Crash、保存、認証、Media、AI fallbackを共通形式へ正規化するprovider-neutral contractを追加した。既定sinkはNo-opであり、Privacy承認前に端末外へ自動送信しない。

## Guardrails

- raw exception、Quest/Mission/Task/Trail本文、Arc会話、email、電話番号、tokenをschemaへ持たない。
- operation、error codeなどは固定token形式だけを許可する。
- evidence収集失敗が本来の操作を失敗させない。
- external reporter、global handler、hosted dashboardはまだ有効化しない。

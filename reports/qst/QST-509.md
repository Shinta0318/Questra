# QST-509 Achievement Loop Closure

## Summary

Task完了後の体験を、単なる状態変更やSnackBarから、Arcの祝福、親付きTrail記録、
次Task／Mission成果確認へつながる共通モーメントへ統一した。

## Changes

- `TaskAchievementService`で同じMissionの実行可能Taskを優先する次行動を決定した。
- 必須Taskが揃った場合はMission成果確認を優先し、自動Mission完了は行わない。
- Arc CelebrationへTask完了イベントと自然な日本語を追加した。
- Task一覧、Task詳細、Quest Journey Workspaceへ共通完了モーメントを接続した。
- Trail CTAはQuest、Mission、Taskの親情報を作成画面へ渡す。
- 完了取り消しと、次のTaskまたはQuest航路へ進む操作を維持した。
- 390px／200%文字でもscrollしてCTAへ到達できるテストを追加した。

## Master Spec Alignment

- 成功だけでなく行動と記録を価値として扱う。
- Arcは前進を祝い、利用者の代わりにTrailを作らない。
- Quest → Mission → Task → Trailの階層とMission成果確認を維持する。

## Residual Risk

- 物理AndroidのTalkBack、触覚、音、Reduce Motionは未実施。
- 実SupabaseでTask完了RPCが遅延・失敗した場合のモーメント表示タイミングは未実証。
- 複数端末で同じTaskを同時完了した競合はHosted証跡が必要。

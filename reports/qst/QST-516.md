# QST-516 QST-507-515 Cross-functional Quality Review

## Executive Summary

QST-507からQST-515で、主要画面の状態契約、保存失敗からの回復、Task達成導線、owner切替、同一owner直列化、古いTask snapshot拒否、航路承認失敗の伝播、ローカル補償復旧、Quest・Mission保存完了待機までを段階的に強化した。静的解析は警告0件で、対象回帰もPASSしている。

一方、横断レビューでは次のP0を確認した。

1. Flutterの航路snapshotはMission内容を含む拡張形式へ進んだが、Supabaseの`capture_route_state`は旧形式・`snapshotVersion: 1`のままである。DBから再読込した未承認提案をFlutterで比較すると、実変更がなくてもstaleになり得る。
2. 航路の「元に戻す」はQuest・Mission保存を待たず、失敗結果をUIへ返さない。Undo用snapshotも成功確認前に破棄している。
3. Taskの`saveAll`は端末内snapshot競合を防ぐ一方、Supabaseへはversion条件なしのupsertであり、別端末の通常編集を上書きし得る。
4. Hosted証跡は`a5e0cad...`、現在HEADは`141f091`で、remote migration headも`202608080006`のままである。現行候補のRLS・RPC・失敗注入証跡ではない。

## Findings

### Critical / P0

#### F-516-01 Route snapshot schema drift

- Flutter: `route_snapshot_service.dart`はMissionのtitle、description、doneCondition、expectedOutput、期間、難易度、sourceRequirement、confidenceを比較する。
- DB: `202608080006_route_proposal_stale_conflict_guard.sql`はこれらを含めず`version: 1`のまま。
- 影響: 再起動・別端末で再読込したpending proposalが偽staleになり、承認できない。
- 対応: QST-517。

#### F-516-02 Undo acknowledgement and snapshot lifetime

- `undo`は最初にmemory snapshotをremoveし、Quest/Mission復元をawaitしない。
- UIは`unawaited`で呼び、失敗・部分復旧・成功を通知しない。
- 影響: 「元に戻す」を押しても一部だけ残り、再試行材料も失う可能性がある。
- 対応: QST-518、QST-519。

#### F-516-03 Remote Task lost update

- QST-512のrevisionはprocess-local。
- `SupabaseTaskRepository.saveAll`はversion条件なしのupsertで、通常更新時にversionを進めない。
- 影響: 別端末・再読込前の編集が新しいTaskを上書きし得る。
- 対応: QST-521。

#### F-516-04 Current-SHA hosted proof gap

- 現在HEAD: `141f091`。
- Cloud evidence source: `a5e0cad...`、working tree clean=false。
- local headとremote migration headが一致していない。
- 対応: QST-525。QST-343/QST-349完了後の候補SHAでのみ実行する。

### High / P1

#### F-516-05 Crash-safe local compensation

Quest、Mission、Taskのローカル補償はprocess memoryのsnapshotに依存する。保存途中の強制終了後に再開できるjournalがない。Mock previewを実データ保証と誤認させない表示も必要。

対応: QST-520。

#### F-516-06 Proposal provenance

DBには`generated_by: arc`のみ保存され、heuristic ruleset、Gemini model、prompt、schema、groundingの区別がない。UIで生の内部実装名を見せる必要はないが、監査情報は保持する必要がある。

対応: QST-522。

#### F-516-07 Recovery accessibility and state completeness

primary state matrixは契約化されたが、航路適用中、Undo中、復旧失敗、偽stale、offlineのGolden/物理アクセシビリティ証跡がない。

対応: QST-523、QST-524。

# QST-488 Trail Composer Accessibility Contract

## Goal

Trail作成時のQuest／Mission選択を視覚だけに依存させず、読み上げと文字拡大でも親階層を理解できるようにする。

## Implementation

- Quest selectorへ「Trailを紐づけるQuestを選択」のSemantics labelを追加した。
- Mission selectorはQuest未選択と選択済みで読み上げlabelを切り替える。
- Mission不足時の回復CTAに「選択したQuestでMission作成画面を開く」を付与した。
- 長いQuest／Mission名を使い、360px、200% text scaleのWidget testを追加した。
- 既存の視覚label、helper、validation copyは維持した。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_488_trail_accessibility_contract_test.dart`

## Validation

- Trail accessibility contract: 1 test passed.
- QST-479 / QST-480 regression remained passing during implementation.

## External boundary

Widget Semanticsは実端末TalkBackの読み上げ速度、フォーカス復帰、Bluetooth keyboard操作を代替しない。物理Android証跡はcandidate SHA固定後に必要である。

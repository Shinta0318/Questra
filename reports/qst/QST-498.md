# QST-498 Trail Hosted Ownership Evidence Contract

## Goal

Trailが選択したQuestと、そのQuestに属するMissionへだけ保存されることを、現candidateのHosted Supabaseで再実証できる契約にする。

## Implementation

- `rls_behavior.sql`へ正しいQuest／Mission親へのTrail作成assertionを追加した。
- 同一ownerの別Quest Missionを指定するcross-parent writeを拒否するassertionを追加した。
- 別ownerのQuest／Missionを親にするcross-account writeを拒否するassertionを追加した。
- cloud captureへTrail親契約のsanitized結果を追加した。
- verifierはSQL assertion、capture fields、evidence shapeを必須化した。
- 現在の証跡は`pending_current_candidate_replay`とし、過去実行を現candidateの証明に流用しない。

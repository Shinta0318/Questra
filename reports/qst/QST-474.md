# QST-474 Trail Media Stale Response Guard

## Goal

Trail削除、ログアウト、利用者切替後に、処理中だった画像responseが古いattachmentを画面へ再表示しないようにする。

## Implementation

- Trail画像loadの全呼び出しでgenerationを先に更新する。
- 空Trail一覧と未ログイン状態も既存requestを無効化する。
- response適用前にgenerationとownerを再確認する既存guardを維持した。
- Trailが空になった場合はattachment stateを即時破棄する。
- 遅延response完了後も空stateを維持するrace testを追加した。

## Evidence

- `apps/mobile/lib/features/trail/trail_controller.dart`
- `apps/mobile/test/qst_474_trail_media_stale_response_test.dart`

## External boundary

非同期raceは制御可能なRepositoryでローカル検証する。実Storage遅延とアプリbackground復帰はdevice evidenceで確認する。

# QST-268 Trail First Record UX and CTA Consolidation

## Result

Completed.

Trailが0件のユーザーでも、画面を開いた直後に最初の記録を始められるよう導線を一本化した。保存中、保存失敗、再試行を作成シート内で扱い、成功したTrailは即座にTimelineへ反映される。

## Main Changes

- Arc案内直下に、画面内で唯一の主CTAを配置
- 空状態、Timeline、画面下部に重複していた作成CTAを削除
- 0件時は「最初のTrailを残す」、記録後は「Trailを残す」と表示
- 作成シートの送信処理を非同期化
- 保存中インジケーターと二重送信防止を追加
- 保存失敗時はシートを閉じず、入力を保持して再試行可能にした
- 保存失敗時の楽観的な一時Trailを取り除き、表示と永続化の不一致を防止
- 成功時は新しいTrailをTimelineへ即時反映
- 共通のArc空状態で、操作ボタンを必要な場合だけ表示可能にした

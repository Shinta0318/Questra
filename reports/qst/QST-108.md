# QST-108 Adaptive Navigation Rail

## Status

Done

## Summary

Added adaptive tablet and expanded-screen navigation while preserving the same
destinations and branch behavior as compact Bottom Navigation.

## Implementation

- Moved destination metadata into `QuestraNavigationDestination`.
- Bottom Navigation and Navigation Rail now share route order, labels, and
  icons.
- Compact widths below 600px keep Bottom Navigation.
- Medium widths use a compact labeled Navigation Rail.
- Widths of 1200px and above use an extended Navigation Rail.
- Arc remains visually emphasized in both navigation presentations.
- AppShell keeps each branch's navigation history when the navigation form
  changes.
- Added a shared extended-navigation breakpoint.

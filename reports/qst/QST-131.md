# QST-131 Report: Navigation and Creative UI Refresh

## Summary

Refreshed the beta MVP navigation and major surfaces around the primary flow
`Home -> Arc -> Quest`. Arc is now more clearly the product entry point, Home
shows the user's current journey context, Arc has a command-center surface, and
Quest cards feel more premium and less like a default list.

## Changed Screens

- Home: added an Arc-centered journey flow card connecting current Mission,
  Arc guidance, and Quest progress.
- Arc: added a journey command center with Quest, Mission, Trail counts and
  shortcuts for Quest Guide, Reflection, and Horizon.
- Quest: refreshed Quest cards into poster-like premium cards with progress,
  next Mission copy, Arc comment, difficulty, category, and status chips.
- Settings: replaced placeholder copy with a Japanese settings surface and
  an Arc tutorial replay action.

## Added Components

- `OnboardingTourController`
- `QuestraOnboardingTour`
- Home journey flow card components
- Arc command center card components

## Before / After

- Before: bottom navigation placed Arc after Guild, and Arc was visually
  available but not positioned as the central route into Quest planning.
- After: navigation order now starts `Home -> Arc -> Quest`, and the first-use
  tour teaches that same flow.
- Before: Arc Chat was mostly a conversation surface.
- After: Arc shows a command-center card before chat, making Quest guidance,
  Reflection, and Horizon visible.
- Before: Quest cards were clean but close to a standard app list.
- After: Quest cards use dark cinematic gradients, stronger hierarchy, and
  next-Mission context.

## Acceptance

- Home -> Arc -> Quest flow is reflected in navigation and first-use guidance.
- Home keeps today's Mission, active Quest, recent Trail, Guild, Star Map, and
  Horizon visible.
- Arc is not described as an AI assistant.
- Visible new copy uses Quest, Mission, Trail, Guild, Arc, and Horizon terms.
- First-use tutorial is skippable and can be replayed from Settings.
- Tutorial state has a Supabase profile column with local in-session fallback.

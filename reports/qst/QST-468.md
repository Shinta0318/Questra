# QST-468 Trail Parent Domain Validation

## Goal

UI以外の呼び出しでも、Trailが異なるQuestのMissionやTaskへ誤って紐づくことを保存前に検出する。

## Implementation

- Quest／Mission／Task階層を検証する純粋なdomain validatorを追加した。
- archived Quest、removed Mission、cross-Quest Mission、cross-Mission Taskを拒否する。
- Controllerのstate変更前にvalidatorを実行し、不正Trailを一瞬も一覧へ追加しない。
- 親データが未ロードの起動直後は`unresolved`として構造検証を維持し、DB trigger／RLSで最終確認する。
- UIの候補制限、client domain validation、DB triggerの三層を維持する。

## Evidence

- `apps/mobile/lib/features/trail/trail_parent_validator.dart`
- `apps/mobile/lib/features/trail/trail_controller.dart`
- `apps/mobile/test/qst_468_trail_parent_domain_validation_test.dart`

## External boundary

純粋domain契約はローカル検証する。`unresolved`経路の最終拒否はhosted Supabase triggerと二アカウントRLS証跡が必要。

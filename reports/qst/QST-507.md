# QST-507 Primary Screen State Matrix Contract

## Summary

主要6画面の目的、CTA、状態、証跡を機械可読なmatrixへまとめた。画面が描画できる
だけで状態網羅や実機確認まで完了したと扱わない証跡levelも定義した。

## Changes

- Home、Arc、Quest、Trail、Profile、Onboardingを正本へ登録した。
- empty、content、loading、saving、error、offline、AI generating／fallbackを整理した。
- 各画面へ既存Widget Testを紐づけた。
- Compact 390x844、200%文字、`ja_JP`、dark、reduce motion、日本語fontをGolden条件とした。
- candidate SHA bindingと物理証跡非代替を必須にした。
- matrix verifierと契約テストを追加した。

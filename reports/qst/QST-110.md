# QST-110 Home Information Hierarchy Polish

## Summary

Home画面の情報優先度を整理し、Arc greetingのあとにToday's Mission、Active Quest、Recent Trails、Guild Activityが順に見える構成へ更新した。

## Master Spec Alignment

- Quest、Mission、Trailの循環がHomeから自然に始まる構成へ寄せた。
- Trailは投稿数ではなく挑戦の記録として扱い、Recent Trailsとして振り返り導線を置いた。
- Guildは人気競争ではなく相談・共助の入口として表示した。
- ArcをAI assistantとは表現していない。
- 複雑なBackend変更や課金導線は追加していない。

## Implementation Notes

- Homeの主要順序:
  1. Captain status
  2. Arc greeting
  3. Arc Signal / Mission Signal
  4. Today's Mission
  5. Active Quest
  6. Recent Trails
  7. Guild Activity
  8. Star Map / Horizon
- Active Questは実Questデータを優先し、空の場合はQuest作成導線を表示する。
- Today's Missionは未完了Missionを表示し、空の場合はQuest作成から始める導線にする。
- Recent TrailsとGuild Activityは空状態でも次の行動が分かる表現にした。
- 旧モックQuestカードはHomeの主表示から外した。

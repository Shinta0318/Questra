# QST-139 Star Map Graph Bridge

## Summary

Challenge Graph InsightをStar Map Recommendationへ接続した。
これにより、Mission不足やReflection不足などのGraph上のギャップが、HomeのStar Map候補として説明可能に表示できる。

## Changed Files

- `apps/mobile/lib/features/star_map/star_map_recommendation_service.dart`
- `apps/mobile/lib/features/home/home_screen.dart`
- `apps/mobile/test/star_map_recommendation_service_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-139.md`

## Implementation Notes

- `StarMapRecommendationService.recommend`に任意引数`graphInsights`を追加した。
- 既存呼び出しとの互換性を保つため、デフォルトは空リストにしている。
- Challenge Graph由来候補は`challenge_graph_<insightType>`の`sourceType`を持つ。
- Homeでは進行中QuestのGraph Insightを集め、Star Map推薦へ渡す。
- Supabase、Graph DB、課金制御は追加していない。

## Acceptance

- Star Map推薦がChallenge Graph Insightを受け取れる。
- Graph Insight由来の候補が説明可能な`sourceType`を持つ。
- HomeのStar Mapが進行中QuestのGraphギャップを推薦に使える。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

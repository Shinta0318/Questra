# QST-446 AI Reconciliation Scheduler and SLA Alerts

## Status

Completed locally. Hosted migration deployment, scheduler activation, webhook receipt, and recovery drill remain QST-447 external evidence.

## Goal

StaleなAI予算予約の分類、期限切れoperator claim回収、queue SLA監視を、既定OFFかつ冪等なserver workerへ移す。通知へ利用者識別子やQuest内容を含めず、provider実行や利用量を証拠なしで推測しない。

## Implementation

- Scheduler control、schedule-slot run ledger、privacy-safe SLA alert queueを追加した。
- Controlとservice worker identityを既定OFFにした。
- Schedule keyをSHA-256 digestで一意化し、同一slot再送でcaseやattemptを重複させない。
- QST-441のreceipt-aware stale classifierを再利用した。
- 期限切れoperator claimを`FOR UPDATE SKIP LOCKED`で回収し、service worker eventとして監査する。
- Alert deliveryにも15分leaseを設け、worker停止後に再取得できるようにした。
- Worker runとalert deliveryへ上限付きretryとallowlist error codeを追加した。
- Edge Functionをserver secret、Service Role、timeout、HTTPS、HMAC署名で保護した。
- Webhook payloadをseverity、件数、age bucketだけに限定した。
- Kill switch、有効化順序、forward-safe rollback、QST-447 hosted drillを文書化した。

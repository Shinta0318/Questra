# QST-359 User Data Export and Deletion Operations Report

Date: 2026-08-25  
Status: ImplementedExternalEvidencePending

## Review Finding

QST-291/309でexport、Task削除、account削除予約の基盤は存在したが、exportは件数表示だけで実データを持ち出せず、訂正依頼UIがなく、個人情報共有は「撤回可能」という表示に反してSettingsとDBの両方が撤回を拒否していた。

## Corrections

- owner-scoped export payloadを明示操作でJSONとしてクリップボードへコピー。
- clipboardの機密性注意を表示。
- Profile、Arc Memory、Quest DNA、Tagの訂正依頼UIとRepositoryを追加。
- correction targetをallowlist化し、本文を5〜500文字へserver側制限。
- account deletion scopeをclient入力から切り離し、server側の固定retention exceptionへ正規化。
- 個人情報共有はcontextual promptからのみ付与できる一方、Settingsからいつでも撤回可能に修正。
- 撤回時に企業向け派生signalを削除。
- Privacy/Release copyを実装状態へ同期。ただしhosted証拠がないため外部利用可能とは表示しない。

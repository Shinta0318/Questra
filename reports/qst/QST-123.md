# QST-123 Beta Empty State Verification

## Summary

新規Betaアカウントとアカウント切替時のQuest、Mission、Trail状態を監査し、本番fallbackのモックTrailを除去した。各Controllerは所有者変更を検知すると即座にローカル状態を空にし、古い所有者の非同期結果を破棄する。

## Implementation Notes

- Quest、Mission、Trailの匿名初期状態を空配列へ統一した。
- `TrailController`に残っていた`mock-quest-arc`由来の2件を本番コードから除去した。
- 認証済み状態からControllerが初期化された場合も、現在の所有者データを自動読込する。
- ログアウトまたはアカウント切替時は、リモート読込を待たずにJourney状態を空にする。
- 読込・保存中に所有者が変わった場合、古い非同期結果で現在の状態を上書きしない。
- 旧Trail/Guild画面の回帰テストは、製品fallbackではなく明示的な日本語fixtureを使用する。
- GuildとTrailの本番RouteはQST-158のComing Soon状態を維持する。

# QST-477 Trail Keyset Pagination

## Goal

Trail一覧の追加読込をoffset方式から安定したcursor方式へ移行し、閲覧中の新規投稿による重複・欠落を防ぐ。

## Implementation

- `created_at`と`id`を組み合わせた`TrailPageCursor`を追加した。
- Repository契約をoffsetから`before` cursorへ変更した。
- Supabase queryはowner境界を維持し、`created_at DESC, id DESC`の複合順序でcursor以前だけを取得する。
- In-memory Repositoryも同じ順序と境界条件を実装した。
- Controllerは最後にremoteから消費したTrailを次cursorとして保持する。
- ローカル追加件数をページ境界に使用しない。
- 同時に新しいTrailが挿入された場合と、同一時刻のID tie-breakを回帰テストした。

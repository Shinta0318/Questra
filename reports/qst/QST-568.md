## Change

`run_mock.ps1 -Offline` now starts Flutter Web in profile mode. This preserves the non-release `AUTO_ENTER_LOCAL_MOCK` gate while avoiding the fresh-tab debug DDC load that left the Guild preview blank. The connected launcher and release-mode auto-entry restriction are unchanged. The runbook describes the profile build delay and its restart requirement.

## Verification

- The original debug server returned HTTP 200 but a new browser tab remained white; console logs showed a 1,236-script DDC load and no usable Guild UI.
- A release-mode build rendered but redirected `/#/guild` to `/#/login?continue=/guild`, as required by the existing release safety rule. It was stopped.
- A profile-mode build with `APP_ENVIRONMENT=development`, `ALLOW_MOCK_PERSISTENCE=true`, and `AUTO_ENTER_LOCAL_MOCK=true` rendered `http://127.0.0.1:5292/#/guild` without login. The Japanese font settled after initial load.
- The updated `run_mock.ps1 -Offline -Port 5293` built in profile mode and rendered `http://127.0.0.1:5293/#/guild` in the in-app browser without login. The Guild empty state and Arc CTA were visible after font loading. The launcher was restarted as a hidden background process and the browser was reloaded; the same screen rendered again. This tab remains open for review; redundant 5290/5292 trial servers were stopped.
- `dart run tools/qst/verify_connected_preview_launcher.dart`: PASS. `dart run tools/qst/verify_backlog_ssot.dart`: PASS (514 IDs). `git diff --check` on the changed tracked files found no whitespace errors, only existing LF/CRLF conversion warnings.

This mode is intentionally offline and in-memory. It does not prove Supabase Auth/persistence, Gemini responses, real Guild public data, or Android behavior. External Beta remains NO-GO.

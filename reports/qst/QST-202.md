# QST-202 Quest DNA V2 Persistence

Status: In Progress
Priority: P1

## Implemented

- 16 Master Spec attributes (`category` through `enterprise_relevance`) are represented by `QuestDna` with a version, evaluation time, and provenance.
- Quest repository persists and retrieves the bounded JSON snapshot with its version metadata.
- Arc Quest Guide requests structured Quest DNA and uses a bounded local fallback when provider output is unavailable.
- Quest guide adoption persists the evaluation and DNA snapshot together.
- Migration `202607310001_quest_dna_v2.sql` adds the owner-bound JSON column and validation constraint.

# QST-417 Connected External Preview Bootstrap

更新日: 2026-09-08 / 状態: ImplementedValidationPending

## 背景

SupabaseとGeminiを利用するレビュー用Web版を起動する際、公開クライアント設定の所在、mock/remoteの区別、未配備migration、Gemini Secretの責務が一つの手順になっていなかった。結果として、外部連携を有効にした表示をその場で再現できず、過去ログからキーを探す危険な運用へ寄りやすかった。

## 実装

- リポジトリ外の設定または現在プロセスの環境変数だけを受け付ける`run_connected_preview.ps1`を追加した。
- Hosted HTTPS URL、publishable/legacy anonキー、project refを検査し、secret/service roleを拒否する。
- Supabase AuthとData APIの公開probe後、`APP_ENVIRONMENT=production`、mock persistence無効でFlutter Webを起動する。
- client設定は一時JSONを介してFlutterへ渡し、終了時に削除する。キー値はログへ表示しない。
- GeminiはFlutterへキーを渡さず、認証済みArc ChatからEdge Functionを通す契約を明文化した。
- 正常、secret、service role、サーバー秘密名、HTTP URLの5シナリオを追加した。
- Release Gateへ静的verifierとPowerShellテストを接続した。

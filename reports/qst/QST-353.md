# QST-353 Consentful Trail Sharing and Ethical Referral

## Status

Implemented as a privacy-first sharing foundation. Public creation remains
feature-flagged/off until hosted Supabase migration, abuse tests, and recipient
landing evidence are complete.

## Summary

Trail sharing now has a domain policy and database contract that only permit a
user-selected immutable text snapshot. Images, owner data, Quest/Mission links,
and live Trail rows are deliberately excluded. The policy requires at least one
selected field, an expiry within 30 days, and rejects email/phone-like content.

## Security Contract

- Direct table access is denied to `anon` and `authenticated` roles.
- Link tokens are 256-bit random values; only their SHA-256 hash is stored.
- `resolve_trail_share_link` returns a snapshot only while the token is valid
  and not revoked.
- `revoke_trail_share_link` is owner-scoped and takes effect immediately.
- Server-side create RPC verifies owner, selected fields, and expiry before
  creating the snapshot.

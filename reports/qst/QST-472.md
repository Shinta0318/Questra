# QST-472 Trail Delete Recovery

## Goal

Trail削除の完了を待機可能にし、通信失敗時に表示順と入力履歴を壊さず復元する。

## Implementation

- `removeTrailAndWait`を追加し、削除成否を呼び出し元へ返すようにした。
- 削除前のindexとTrail snapshotを保持する。
- Repository失敗時は同じ位置へ復元する。
- 同じIDが別処理で復帰済みの場合は重複復元しない。
- ローカル未ログイン利用では従来どおり端末stateから削除できる。
- 削除確認ダイアログは結果確定までController処理をawaitする。

## Evidence

- `apps/mobile/lib/features/trail/trail_controller.dart`
- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_472_trail_delete_recovery_test.dart`

## External boundary

失敗rollbackと順序復元はローカル検証する。hosted Supabaseでの削除RLS、timeout、二重操作は外部証跡が必要。

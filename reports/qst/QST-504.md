# QST-504 Arc-First Quest Entry Return Contract

## Summary

Quest作成のPrimary entryをArc相談へ維持しながら、Quest一覧から開いた相談に
安全なreturn contextを追加した。QST-322の残件を本QSTで置き換えた。

## Changes

- Quest一覧の作成CTAを`arcForQuestCreation`へ統一した。
- ArcでQuest起点は「Questへ戻る」、Mission起点は「Missionへ戻る」と表示する。
- return locationを同一アプリの`/quest`または`/quest/...`だけへ制限した。
- 外部URL、Home等への任意redirectを拒否する。

## Validation

- `flutter test --no-pub test/qst_504_arc_first_quest_return_test.dart test/bottom_navigation_v2_test.dart test/qst_410_arc_quest_handoff_recovery_test.dart`
  - PASS: 13 tests
- AI計画失敗時に手動Questだけを保存し、Missionを生成しない既存契約も回帰した。

## Residual Risk

- OS deep linkからの復帰はcandidate-bound Web／Android E2Eで別途確認する。
- `/quest/create`は編集・回復用routeとして残すがPrimary CTAからは直接開かない。

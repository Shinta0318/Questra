# QST-276 Legacy Template Fallback Retirement Report

## Result

Completed on 2026-08-08.

All reachable configured planning paths now preserve user input and return a
retryable/manual continuation state when Gemini is unavailable. They no longer
manufacture fixed Quest or Mission bodies that could be mistaken for a
personalized Arc plan.

## Changes

- Removed fixed Quest alternative, guide and Mission regeneration fallbacks
  from `arc-quest-guide`.
- Removed fixed Mission fallback from `generate-mission`.
- Removed fixed guide arrays from `generate-quest-guides`.
- Added bounded `503 planning_temporarily_unavailable` responses with the
  operation name, input-preservation marker and manual-path marker.
- Required structurally valid AI output before returning a planning result.
- Removed configured Flutter services' local-template fallback; errors retain
  the entered wish or existing Mission and expose a retry path.
- Kept local generators only at the explicit Supabase-unconfigured development
  and mock boundary.

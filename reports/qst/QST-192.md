# QST-192 Arc Quest Companion Enhancement Report

## Result

Completed. Arc Chatを回答で終わらせず、現在のQuestに対するMission追加、
参考情報追加、期限見直しを提案し、ユーザー承認後だけ反映する
Quest Companionの縦断フローを実装した。

- `ArcQuestChangeProposal`にMission追加、参考情報、期限、削除、分割、統合、
  並べ替え、注意事項の型を定義。
- Arc Chat Edge Functionへ最大3件の構造化変更提案を追加。
- 現在情報が必要な質問だけGemini Grounded Searchを利用。
- Grounding文を信頼せず、HTTPS参照元、Quest ID、Mission ID、文字数を再検証。
- Arc Chatに「反映する / あとで / 追加しない」カードを追加。
- Mission追加は既存の重複チェックとSupabase永続化を再利用。
- 参考情報はMission SupportのGrounded Search導線に接続。
- 企業支援を検索結果から生成せず、審査済みCatalogとの分離を維持。

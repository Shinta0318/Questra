# QST-117 Interaction Animation Pass

## Summary

主要操作入口へ控えめな押下モーションを追加し、操作の手応えを高めた。動きは共通Widgetに集約し、過剰な装飾ではなく明確さを優先した。

## Master Spec Alignment

- Motionは世界観の演出ではなく、操作結果を分かりやすくするために限定した。
- Arc Floating EntryとQuick Actionに、旅路へ戻る操作の手応えを追加した。
- OSのdisable animations設定では押下モーションを無効化し、アクセシビリティを維持した。
- Supabase、保存境界、AI接続、画面構造は変更していない。

## Implementation Notes

- `QuestraMotion.pressedScale`を追加した。
- `QuestraPressable`を追加し、押下中だけ`AnimatedScale`で軽く縮む共通フィードバックを提供した。
- `QuestraPressable`は`MediaQuery.disableAnimationsOf(context)`を尊重し、アニメーション無効時はscaleを変えない。
- Arc Floating EntryとQuick Action Tileへ`QuestraPressable`を適用した。
- 単体テストで押下時scaleとdisable animations時の挙動を固定した。

# QST-448 Gemini Grounding Query Cost Ledger

## Status

Completed locally. Hosted migration deployment and provider-backed reconciliation evidence remain external Beta gates.

## Goal

Google Search groundingのquery原価をtoken費用と分離し、provider metadataから検証できた実行件数だけをversion付きrateで精算する。検索語、URL、Quest内容、利用者識別子を原価台帳へ保存しない。

## Implementation

- Gemini公式価格をeffective date付きのgrounding rate registryへ登録した。
- Google Search toolを要求する処理だけ、最大query数をtoken予算と併せて予約する。
- Interactions APIの`google_search_call`から一意な非空query数を抽出した。
- Provider metadataの宣言件数と抽出件数が一致しない応答を精算しない。
- Provider execution receiptへquery件数とevidence versionを追加した。
- Token費用とgrounding費用を同じDB transactionで精算し、台帳は分離した。
- Base予約の解放・期限切れにgrounding予約を追従させた。
- Service Role限定の日次aggregate viewを追加した。
- 価格不明、receipt不足、未予約query、上限超過をfail closedにした。

# QST-267 Japanese UI Terminology and Copy Consistency

## Result

Completed.

Questraの正式用語を維持しながら、主要画面に残っていた一般的な英語UI文言を自然な日本語へ統一した。プロフィール、認証、設定、Quest、Trail、共通準備画面を対象に、状態、説明、確認ダイアログ、同期表示、ツールチップを修正した。

## Main Changes

- Profileのゲスト状態、初期設定状態、旅の所有者説明、Rank/Bond表示を日本語化
- Authのログイン、登録、パスワード再設定の見出しを日本語化
- Settings Mapと各状態ラベルを、操作内容が分かる日本語へ変更
- Quest Dashboard、Quest Canvas、Quest DNA、Challenge Graph、Milestone関連の見出しを整理
- Questテーマ名、Quest DNA属性名、Guide種別を日本語化
- Trailの画像削除、Trail削除、同期状態、Timeline指標を日本語化
- Coming Soon、Settings、Retry、Dismissなどの共通表示を日本語化
- Quest/Mission/TrailのArc Memoryタイトルを日本語化
- `Story`および`AI Assistant`表現の不在を検証

## Terminology Policy

以下はQuestraの正式な固有語として維持する。

`Questra`、`Arc`、`Quest`、`Mission`、`Task`、`Trail`、`Guild`、`Star Map`、`Arc Memory`、`Stardust`、`Navigator Rank`、`Bond`

一般的な操作、状態、説明、確認文は日本語で表示する。

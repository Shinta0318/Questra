# QST-329 Context-bound Gemini Mission Generation

## Status

Implemented locally. Supabase Edge Function deployment and hosted Gemini
evaluation remain pending.

## Problem

When Gemini Planning was unavailable, the local guide returned generic Missions
such as "達成したと分かる状態を決める" and "今の条件と不明点を分ける".
These are internal planning steps, not outcomes that advance the user's Quest.

## Changes

- Disabled fixed local Mission fallback when Gemini Planning is unavailable.
  The UI keeps the user's input and presents a retryable connection message.
- Expanded travel clarification to five route-changing dimensions: schedule,
  companions, budget, desired activities, and travel style.
- Preserved the clarified answers in the Quest description passed to the
  planning pipeline as explicit `航路条件`.
- Updated Mission generation, critic, and targeted repair prompts with new
  versions requiring direct alignment to explicit user answers.
- Added semantic rejection for internal planning artifacts before a preview can
  be accepted.
- Added non-travel regression coverage so travel-only questions do not leak into
  learning and other Quest types.

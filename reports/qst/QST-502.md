# QST-502 Home Desktop Journey Composition

## Goal

初期Homeの機能を増やさず、desktopで横に伸びすぎる構図を整え、Arcと最初の一歩へ視線を集める。

## Implementation

- Homeのjourney columnへ`maxContentWidth: 920`を設定した。
- compact mobileでは従来どおり利用可能幅いっぱいを使う。
- 初期状態へ新しい説明、統計、空カードは追加していない。
- 再訪時のToday Task、Quest、Trail表示条件は変更していない。

## Validation

- Desktop／mobile composition and Home next-step regression: 5 tests passed.

## UX assessment

広い画面でカードが横長の管理画面に見える傾向を抑え、Premium Life Journeyの読み幅へ近づけた。mobileの情報密度や操作数は変えていない。

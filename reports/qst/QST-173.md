# QST-173 Arc Conversation to Quest Planning

## Status

Implementation complete; detailed Quest Guide generation is deployed to Supabase Beta.

## Goal

Arcとの自然な会話からQuestの種を見つけ、Geminiが道筋と最初のMissionを提案し、ユーザーが確認して保存できる一続きの体験を作る。

## Implemented

- Arc Chat応答に任意の構造化`quest_suggestion`を追加した。
- 「シンガポールに行きたい」のような希望を、旅行カテゴリのQuest候補として扱う。
- Arc画面に「この航路をQuestにする」カードを追加した。
- Quest化前にQuest名、テーマ、難しさ、道筋、注意点、Mission候補を確認できる。
- GeminiとローカルフォールバックのMission候補を、依存順の8〜10件へ詳細化した。
- 各Missionは一つの具体的成果と「完了と言える条件」を説明に含める。
- 旅行Questは目的・候補日、旅券・公式入国条件、予算、移動、宿泊、旅程、予約、通信・現地交通、保険・健康、持ち物まで分解する。
- 確定時に1つのQuestと選択したMissionを保存し、先頭Missionを今日のMissionにする。
- 生成済みArcガイドをQuest詳細へ引き継ぎ、同じAI生成を重複実行しない。
- Gemini未接続時も、明確な希望表現だけをローカル判定して同じ導線を維持する。
- 通常のQuestフォームへArc相談導線、テーマ選択、簡潔な難易度選択、折りたたみ式の保存・公開設定を追加した。

## Current Flow

1. Arcへ「シンガポールに行きたい」と話す。
2. Arcが会話へ応答し、Questの種を提示する。
3. 「この航路をQuestにする」を選ぶ。
4. GeminiがQuestの要約、段階的な道筋、注意点、8〜10件のMission候補を生成する。
5. ユーザーがMissionを選び、QuestとMissionをまとめて保存する。

## Security and Stability

- Gemini APIキーはSupabase Edge Functionだけで使用する。
- クライアントへ秘密鍵を配置しない。
- 入力は既存の文字数上限と制御文字検査を通す。
- AI生成失敗時は既存のローカルガイドへフォールバックする。
- 通常の質問や振り返りを自動でQuest化しない。

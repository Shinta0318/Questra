# QST-223 Multi-Pass Mission Generation and Critic

Status: Completed

- Added a deterministic critic/validator before Mission preview persistence.
- Rejects duplicate titles, abstract-only Missions, missing done conditions, self dependencies, and unknown dependencies.
- Added a separate Gemini Critic/Repair pass after Planner/Generator output. Good Missions are preserved and only failing candidates are repaired.
- The repair loop is capped at one pass. Provider failure keeps the validated initial route and never erases the user's preview.
- Added bounded `plan_quality` metadata with aggregate score, generation version, Critic pass count, repaired Mission count, and generation time.
- Persisted plan quality on the owning Quest; raw prompts and private Critic reasoning are not stored or shown.
- Applied hosted migration `202608010007_mission_plan_quality.sql` and redeployed `arc-quest-guide`.
- Contract, model, preview, persistence, and startup regression tests passed.

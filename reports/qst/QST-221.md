# QST-221 Adaptive Quest Planning Engine V3

Status: In Progress

## Product Decision

Questraはカテゴリ別テンプレートからMissionを流し込まない。Quest固有の成功条件、制約、現在地を理解し、最小十分な航路を設計する。

## Implementation Sequence

1. QST-222でSuccess Contractと仮定を構造化する。
2. QST-221で固定Mission数とテンプレート生成依存を撤去する。
3. QST-223/224で多段評価とMissionの具体性契約を導入する。
4. QST-231で200件のペルソナ差分評価をリリースゲート化する。

## Compatibility Boundary

Existing Quest、Mission、Routeは読み取り可能なまま維持する。新しい計画属性はバージョン付きで追加し、ユーザーの明示承認なしに既存航路を置き換えない。

# QST-583 Hosted Missing-Consent Denial Probe

Status: In Progress (local probe contract only)

## Finding

The prior Hosted AI auth check sent malformed JSON. Most functions rejected that request before reaching their legal gate, so a 400 response did not prove that a signed-in user without a current acceptance would be stopped before AI work. QST-581's local tests were not a substitute for a Hosted request.

## Change

- Include `quest-planning-tools` in the anonymous and signed-in malformed-request inventory.
- Add an opt-in denial probe for a disposable, signed-in, missing-consent account. It sends only synthetic, benign inputs and checks both HTTP 403 and the exact `consent_required` code for eight entrypoints that do not require owned Quest/Mission fixtures.
- Stop immediately on the first unexpected response so an old Hosted deployment cannot trigger further synthetic AI calls.
- Require `SUPABASE_RUN_CONSENT_DENIAL_PROBE=true`, `SUPABASE_USER_CONSENT_EXPECTED=missing`, and `SUPABASE_USER_JWT` together. The token stays in the local environment and is never printed.
- If both `SUPABASE_TEST_QUEST_ID` and `SUPABASE_TEST_MISSION_ID` are provided from disposable data owned by that same account, probe `quest-planning-v2` and `research-mission-resources` too. Reject missing or malformed fixture pairs before Auth requests. Research uses `force_refresh` so an existing cache cannot bypass the consent gate.

## Verification

- `node --test tools/qst/verify_hosted_ai_auth_boundary.test.mjs`: 9 passed, including exact-code rejection, 503 rejection, missing-function rejection, safe synthetic payloads, early stop, and optional owned-fixture coverage.
- No Hosted denial probe was run. The current dirty worktree is not a deployable candidate; the remote migration and function versions have not been reconciled.

## Remaining Hosted Proof

Run on the same clean candidate as the deployed legal RPC and Edge Functions, using a disposable account with no current acceptance. Prove the eight fixture-free denials and both owner-scoped denials with the optional owned Quest/Mission fixture IDs. An absent or foreign fixture must fail the probe rather than count as consent denial. An isolated consent-lookup outage test and a real AI request from a current-acceptance account remain separate gates. Do not put tokens, raw conversations, or personal Quest content in evidence.

External Beta remains **NO-GO**.

# QST-344 Report: First Ten Minutes Activation Journey

## Status

Implemented local product contract and Home activation surface. Moderated cohort evidence, hosted persistence evidence, and production analytics funnel are still pending.

## Objective

Help a first-time user understand the promise, complete trust/onboarding gates, express one wish, confirm the first Quest, and start the first Task without a long terminology tour.

## Changes

- Added `ActivationJourneyService` to resolve the user's first-ten-minute stage from profile, Quest, Task, and Task load state.
- Added a Home activation card that appears only until the first Task has started or completed.
- Kept first-use language focused on Arc, Quest, and Task instead of introducing the full glossary.
- Routed activation actions to legal/signup, onboarding, Arc wish input, Quest confirmation, or the first Task focus path.
- Added tests for trust gating, wish input, Quest confirmation, first Task, and completion.

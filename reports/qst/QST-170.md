# QST-170 Arc Motion, Haptics, and Experience Preferences

## Status

**Phase 1 and Phase 2 complete; Phase 3 and cloud activation pending**

添付依頼のQST-141は既存の`Challenge Graph Visual Polish`と重複するため、正式BacklogではQST-170へ再採番した。

## 実装概要

- `ExperienceSettings`と3つのオンボーディングプリセットを追加した。
- 設定は端末へ即時保存し、ログイン中はSupabaseへ所有者単位で同期するRepositoryを追加した。
- Arcの11状態を共通`ArcMotionController`で扱い、タップ、長押し、Mission完了から一時反応を発行できるようにした。
- 触覚と効果音を画面から分離するサービス境界を追加した。
- HomeとMission一覧の右スワイプ完了を設定連動にし、明示ボタンを代替操作として維持した。
- 設定画面へ`体験・演出`を追加した。
- OSのアニメーション軽減、Questraの省電力設定、バックグラウンド、`TickerMode`を尊重するようArc描画を更新した。

## Arcデザイン

- 最新の承認済み7表情PNGをそのまま使用する。
- `arc_normal.png`、`arc_excited.png`、`arc_support.png`、`arc_serious.png`、`arc_worried.png`、`arc_lonely.png`、`arc_celebrate.png`を状態に応じて切り替える。
- 表情名や「ノーマル」「喜び」などの文字を画像上へ表示しない。
- ナビゲーション内のArcはタブ操作を妨げないよう対話を無効化し、画面内のArcだけがタップへ反応する。

## 設定項目

- Arcアニメーション: 通常 / 控えめ / オフ
- 触覚フィードバック: オン / オフ
- 効果音: オン / オフ
- 達成演出: 通常 / シンプル / オフ
- 画面アニメーション軽減: オン / オフ
- スワイプ操作: オン / オフ
- 省電力モード: オン / オフ

初期値は`静かな体験`とし、Arcは控えめ、触覚はオン、効果音はオフ、スワイプはオンにした。

## Mission・Arc操作

- Arc通常タップは軽い触覚とhappy反応を発行する。
- Arc長押しは同じ反応を連続させず、happy/listening/worriedを順番に切り替える。
- Arc操作は500ミリ秒のクールダウンを持つ。
- Mission右スワイプと完了ボタンは同じ完了処理、success触覚、Arc cheering、効果音境界を使用する。
- スワイプをオフにしても完了ボタンは残る。

## Supabase変更

- `user_experience_settings`を追加した。
- enum相当値をCHECK制約で限定した。
- RLSを有効化し、select/insert/update/deleteを`auth.uid() = user_id`へ限定した。
- ローカル保存失敗やリモート同期失敗で主要操作を停止しない。

## アクセシビリティ・性能

- OSのreduce motionを最優先する。
- 省電力または画面アニメーション軽減時はArc motionを控えめへ制限する。
- Arc motionオフでも最新PNGの表情差分によるタップ反応は残す。
- 非表示Ticker、バックグラウンド、非アクティブ状態ではAnimationControllerを停止する。
- Arc画像読込失敗時は既存の生成フォールバックを維持する。
- SemanticsにArcタップ反応を設定する。

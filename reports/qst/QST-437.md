# QST-437 Gemini Tool-only Interaction Boundary

## Status

Validated / local verified

## Problem

QST-435の空応答判定は、本文を返さず`requires_action`とfunction callだけを返す正当な
Interactions応答もmalformedとして拒否していた。

## Changes

- textと同時にtool callを抽出する。
- tool callが一件以上ある場合だけ本文なし応答を許可する。
- tool-only応答ではStructured OutputのJSON解析を保留する。
- responseの`status`を`finishReason`として優先保存する。
- Adapterはtoolを実行せず、構造化引数を上位orchestratorへ返すだけに限定する。
- toolを伴わない空応答は従来どおりfallback後にfail closedする。

## Validation

- Node mockで`requires_action`、function call 1件、本文なし、usage精算を確認する。
- 既存の空応答mockがmalformed outputを維持することを確認する。
- Flutter contract testとBacklog SSOTを実行する。

## Security and Privacy

tool callを受け取っただけでは実行・永続化しない。実際のtool実行はQuestra Tool Serverの
認可、RLS、引数schema、利用者承認を通す必要がある。

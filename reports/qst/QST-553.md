## Finding and change

The local `auth-login` function directly awaited the Supabase password grant without a timeout or transport catch. An Auth 5xx was returned as generic invalid credentials, and `record_auth_login_success` errors were ignored before returning session tokens. A rejected password could also turn into an uncaught function error if the failure-counter RPC threw.

The password grant now has a 10-second timeout and returns a sanitized 503 on transport failure or Auth 5xx. HTTP status takes precedence over a misleading error code in the Auth response body. Failure- and success-counter RPC results are checked, including thrown errors. A successful password grant is not returned to the client unless the success counter is recorded. No account-existence detail or secret is added to responses.

## Verification and limits

- `node --test supabase/functions/auth-login/auth_error.test.mjs supabase/functions/auth-login/auth_io.test.mjs`: 6/6 passed; the tests cover Auth status precedence, request shape, transport failure, successful RPC, returned DB error, and thrown DB error. The QST-552 round-trip probe tests also pass 5/5 (11 combined).
- `node --check supabase/functions/auth-login/auth_io.ts`: passed syntax check. Deno typecheck and deployed Edge Function behavior were not available here; helper tests are not full handler integration tests.
- This patch does not resolve a genuinely incorrect password. QST-552's real confirmed-account login and owner-profile probe is still pending user-completed password recovery or a privately provisioned test account.
- The existing `record_auth_login_success` and `record_auth_login_failure` database RPCs return `void`. A successful RPC response does not prove that a row was updated if the account disappeared concurrently, nor does it make the lock check and success reset one atomic decision. This remains an unverified DB/Edge contract to address before claiming lockout race safety; no existing migration was rewritten in this QST.
- No schema, hosted function, or production account was changed. External Beta remains NO-GO.

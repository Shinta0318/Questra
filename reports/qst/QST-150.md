# QST-150 Arc Memory Settings Card Extraction

## Summary

QST-149に続き、Arc Memory管理プレビューをSettingsScreenから専用Widgetへ移した。
SettingsScreenはPreview生成と画面の並びを保ち、記憶種別・管理アクション・状態表示をWidget内に閉じ込めた。

## Changed Files

- `apps/mobile/lib/features/settings/settings_screen.dart`
- `apps/mobile/lib/features/settings/widgets/arc_memory_management_preview_card.dart`
- `apps/mobile/test/arc_memory_management_preview_card_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-150.md`

## Implementation Notes

- `ArcMemoryManagementPreviewCard`を追加した。
- Quest / Mission / Trail / Bond / Emotionの記憶種別表示を保持した。
- 確認・削除・感度管理・エクスポートの管理アクションと状態表示を保持した。
- データ削除、エクスポート、外部接続、同意状態の変更は追加していない。

## Acceptance

- Arc Memory管理プレビューが再利用可能なWidgetになっている。
- 記憶種別と管理アクションの表示が維持されている。
- SettingsScreenはPreview生成と画面構成を引き続き担当する。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

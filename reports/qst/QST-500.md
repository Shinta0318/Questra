# QST-500 Trail Filtered Pagination Discovery CTA

## Goal

選択中のQuest／Missionに該当するTrailが現在pageにない場合、未記録と誤解させず、過去pageをその場で探せるようにする。

## Implementation

- filter emptyの説明直下へ既存load more controlを移した。
- 同じload more controlが画面下部にも重複しないよう表示条件を整理した。
- 「読み込んだ範囲にない」と「この航路にまだない」の既存copyを維持した。
- この航路へのTrail作成と、すべてのTrailへ戻る操作を同じ空状態に残した。

## Validation

- Filter pagination disclosure and CTA placement: 2 tests passed.

## External boundary

本QSTはclient-side paginationの誤解を減らすUI改善であり、server-side scoped queryへの変更ではない。Hosted query latencyと全履歴探索回数はQST-499の性能境界と実機profileで別途評価する。

# QST-475 Trail Filter Pagination Disclosure

## Goal

選択中のQuest／MissionにTrailが見つからなくても、未読込ページが残る場合に「存在しない」と断定せず、過去のTrailを追加読込できることを明確にする。

## Implementation

- filter結果が空でもpaginationに続きがある場合は、現在の読込範囲だけを対象にした表現へ変更した。
- 過去のTrailに一致する記録がある可能性を補足した。
- 既存の「過去のTrailをさらに表示」操作を同じ状態で表示する。
- 全ページ読込後は従来どおり、この航路にTrailがないことを明示する。
- 断定表示と追加読込可能表示を分けるWidget testを追加した。

# QST-148 Settings Component Extraction

## Summary

Settings画面の保守性を改善する最初の分割として、Arcチュートリアルの表示責務を専用Widgetへ移した。
状態管理と画面遷移は`SettingsScreen`に残し、専用Widgetへcallbackを渡す構造にして既存挙動を維持した。

## Changed Files

- `apps/mobile/lib/features/settings/settings_screen.dart`
- `apps/mobile/lib/features/settings/widgets/settings_tutorial_card.dart`
- `apps/mobile/test/settings_tutorial_card_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-148.md`

## Implementation Notes

- `SettingsTutorialCard`を追加した。
- Arc表示、説明、再表示ボタン、Quest復帰ボタンのUIを専用Widgetへ移した。
- onboarding controllerとrouterへの依存は親画面に残した。
- データ保存、外部接続、設定状態の変更は追加していない。

## Acceptance

- Arcチュートリアルカードが再利用可能なWidgetになっている。
- チュートリアル再表示とQuest復帰のcallbackが動作する。
- 既存の表示文言と視覚表現を維持している。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

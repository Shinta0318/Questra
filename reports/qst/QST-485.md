# QST-485 Trail Composer URL Lifecycle

## Goal

URLから開いたTrail composerを終了した後、`create=1`が残って再読込時に意図せず再表示される状態を防ぐ。

## Implementation

- route起点のcomposer終了後に既存filter callbackを使ってURLを正規化する。
- `create`だけを除去し、Quest IDとMission IDは保持する。
- 保存後は同じQuest／MissionのTrail一覧を継続して確認できる。
- Mission不足からQuest詳細へ移動するhandoffでは正規化を行わず、目的の遷移を上書きしない。
- 通常の画面内CTAから開くcomposerにはURL変更を適用しない。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_485_trail_composer_url_lifecycle_test.dart`

## Validation

- Route-opened composer save and URL lifecycle: 1 test passed.
- Missing Mission handoff regression remained passing during implementation.

## External boundary

ブラウザー履歴全体の再設計は対象外とする。ここではTrail composerの一時的な`create`状態だけをURLから除去する。

## Android Release Configuration

Flutterの既知の`--no-pub`回帰により、`flutter pub get`後のrelease buildで
dev dependencyの`integration_test`が`GeneratedPluginRegistrant.java`へ残り、
release classpathに存在しないplugin classのJava compileが失敗した。

Flutter公式issue #169336の回避策に沿って、Release Gateは
`flutter build apk --config-only`でrelease用plugin構成を再生成してから
`flutter build apk --release --no-pub`を実行する。ignore対象の生成Javaを直接編集する
暫定ツールは削除し、workflowの実行順を回帰テストで固定した。

- Android release APK: PASS、60.8 MB
- `flutter analyze --no-pub`: PASS、0 issues
- `flutter test test/qst_419_android_release_configuration_test.dart --no-pub`: PASS

## Candidate Manifest Policy

- `source_commit` は実装コミット後のclean HEADから取得する。
- `rollback_commit` はその直前コミットへ固定する。
- WebおよびAndroid artifactは同じsource commitから生成し、SHA-256をmanifestへ記録する。
- manifest生成前のworktree cleanlinessを記録する。
- 外部証跡が不足またはSHA不一致のためcandidateはdraftを維持する。
- hosted migration、RLS、provider、physical device、legal、asset権利の古い証跡をcurrent扱いしない。

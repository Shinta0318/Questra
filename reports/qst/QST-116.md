# QST-116 Design System V2 Application

## Summary

Questra Design System V2として、共通Themeのコンポーネント規則を拡張し、主要画面で使われるボタン、IconButton、Tooltip、SnackBar、Card、ListTile、Progress Indicatorの一貫性を高めた。

## Master Spec Alignment

- QuestraのPremium Feeling、Adventure Theme、Deep Navy / Cosmic Blue / Gold Accentを共通Themeへ反映した。
- UIの世界観を壊さず、既存主要フローの構造や保存境界は変更していない。
- QST-115のアクセシビリティ方針を維持し、padded tap targetをThemeへ明示した。
- ArcをAI assistantとは表現していない。

## Implementation Notes

- `AppTheme.light`へ以下の共通コンポーネント規則を追加した。
  - `visualDensity`
  - `materialTapTargetSize`
  - `iconButtonTheme`
  - `floatingActionButtonTheme`
  - `snackBarTheme`
  - `tooltipTheme`
  - `dividerTheme`
  - `listTileTheme`
  - `bottomSheetTheme`
  - `popupMenuTheme`
  - `progressIndicatorTheme`
- `QuestraThemeTokens`へcard radius、button radius、card padding、section gap、component gapを追加した。
- `QuestraCard`が`QuestraThemeTokens`を参照し、glass gradient、radius、shadow、paddingをTheme由来で使うようにした。
- テーマテストでDesign System V2のコンポーネント規則を固定した。

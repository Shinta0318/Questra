# QST-141 Challenge Graph Visual Polish

## Summary

Quest詳細のChallenge Graph Previewを、数値中心の表示から軽量な星図風ノード表示へ磨いた。
Master Spec v2のChallenge Graph思想に合わせ、Questを中心にTheme、Interest、Mission、Trailが接続される感覚をUI上で伝えやすくした。

## Changed Files

- `apps/mobile/lib/features/quest/quest_detail_screen.dart`
- `apps/mobile/test/responsive_screen_smoke_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-141.md`

## Implementation Notes

- `_GraphConstellationPreview`を追加し、Quest中心の星図風カードを表示した。
- `_GraphNodeChip`を追加し、ノード種別ごとに色とアイコンを変えた。
- 追加した表示文は日本語にし、既存のGraph metricsとArc Graph Insightは維持した。
- 新しい依存、Supabase変更、Graph DBは追加していない。

## Acceptance

- Quest詳細で星図風のGraph node surfaceが表示される。
- Quest、Theme、Interest、Mission、Trailのノードが視覚的に区別される。
- 追加ラベルは日本語で表示される。
- 既存のNodes/Edges metricsとArc Graph Insightは残っている。
- Responsive smoke testで表示を検証している。

# QST-462 Trail Scoped Entry

## Goal

Quest／Mission詳細からTrailへ移動したとき、元の航路を見失わず、その文脈の記録だけを確認できるようにする。

## Implementation

- Quest IDと任意のMission IDを保持するTrail URL helperを追加した。
- RouterがURLの親IDをTrail画面の初期フィルターへ渡すようにした。
- Quest詳細のTrail導線を、そのQuestに絞り込んだTrailへ変更した。
- Mission詳細へ、そのMissionに絞り込んだTrail導線を追加した。
- Task起点の親固定composer契約と`create=1`を維持した。
- URLの親が現在データに存在しない場合は、既存のfilter validationにより全Trailへ安全に戻す。

# QST-144 Arc Memory Management Preview

## Summary

QST-143のTrust & Privacy surfaceを受けて、SettingsにArc Memory管理プレビューを追加した。
ユーザーが将来確認できる記憶カテゴリと、レビュー・削除・感度見直し・エクスポートの予定操作を理解できるようにした。

## Implementation Notes

- `ArcMemoryManagementPreviewService`を追加した。
- Quest Memory、Mission Memory、Trail Memory、Bond Memory、Emotion Memoryのプレビューを表示する。
- Settingsに`Arc Memory管理プレビュー`カードを追加した。
- 削除、感度変更、エクスポートはPreview/Planned/Future表示のみで、実データ変更は行わない。
- Supabase mutation、Arc Memory削除API、export APIは追加していない。

## Acceptance

- SettingsでArc Memory管理プレビューが見える。
- 主要なArc Memoryカテゴリが表示される。
- 記憶確認、削除、感度見直し、エクスポートの将来操作が見える。
- 実データ削除・エクスポート・感度変更は行わない。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

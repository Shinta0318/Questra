# QST-450 Provider Receipt Authenticity and Replay Guard

## Status

Completed locally. Hosted binding activation and replay drill remain external evidence.

## Goal

Provider receiptをQuestra serverが発行したnonce、trace、operation、model routeへ結合し、偽造、cross-reservation replay、古い応答再利用を精算前に拒否する。

## Implementation

- Reservation v3へnonce hash、許可model集合、model route digestを追加した。
- Edgeでserver secretから決定的なHMAC nonceを導出し、生nonceをDBへ保存しない。
- Receipt v4でnonce、trace、operation、model route、実行modelを照合する。
- Provider interaction IDのcross-reservation再利用を事前検出した。
- 不一致をallowlist reason付きoperator caseへ送る。
- 精算triggerでverified request bindingを要求できるようにした。
- 同一evidenceの再送は既存digest idempotencyを維持した。
- 既定OFFのFeature Flagで段階導入し、既存AI経路を維持した。

# QST-114 Arc Floating Companion Entry

## Summary

主要画面からArcへすぐ戻れる控えめなFloating Entryを追加し、Arcが旅路に継続して伴走している感覚を強めた。

## Master Spec Alignment

- Arcを画面ごとの孤立した機能ではなく、旅路全体に寄り添うCompanionとして扱った。
- Arc画面では入口を隠し、UIを混ませないようにした。
- ArcをAI assistantとは表現していない。
- 保存処理、Supabase、AI接続、課金導線は変更せず、Beta UX改善に限定した。

## Implementation Notes

- `QuestraArcFloatingEntry`を追加し、Arc画像つきの小さな`Arcへ`入口を提供した。
- AppShellのFloating Action領域を、Arc入口とQuick Action Menuの縦並びに整理した。
- Arc画面ではArc入口を非表示にし、重複した導線を避けた。
- WidgetテストでHomeからArc入口が表示され、タップ後にArc画面では非表示になることを固定した。

## Acceptance

- Users can reach Arc from major screens without making the UI feel crowded: Done
- Arc画面で重複したArc入口が出ない: Done
- Quick Action Menuの既存導線を維持している: Done
- Story表現なし: Done
- ArcをAI assistantとして扱っていない: Done

# QST-111 Quest Dashboard UX Polish

## Summary

Quest Detailの冒頭にJourney Overviewを追加し、Progress、Mission、Trail、Arc Guide、Next Actionを一目で確認できるようにした。

## Master Spec Alignment

- QuestをMissionとTrailへ自然につなげる導線を強化した。
- Arc Guideはユーザーの判断を支える航路として表示し、ArcをAI assistantとは表現していない。
- Trailは挑戦の記録として扱い、次の行動に接続した。
- Backendや保存処理の構造変更は行わず、Beta UX改善に限定した。

## Implementation Notes

- Quest Detailに`Journey Overview`カードを追加。
- Overviewには以下を表示する。
  - Progress
  - Mission完了数/総数
  - Trail数
  - Arc Guide生成状態
  - Next Action
- Next Actionは状態に応じて切り替える。
  - 未完了Missionがある場合: Missionへ
  - Arc Guide未生成の場合: Arc Guideを生成
  - Guide生成済みでTrailがない場合: Trailへ
  - 進行情報が揃っている場合: 次の小さな一歩を促す
- Compact幅のQuest Detail smoke testを追加した。

## Acceptance

- Mission, Trail, Arc Guide, progress, and next action are easy to find: Done
- DashboardからQuest詳細の現在地を把握できる: Done
- Story表現なし: Done
- ArcをAI assistantとして扱っていない: Done

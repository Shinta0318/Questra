# QST-145 Data Export and Deletion Request Copy

## Summary

Master Spec v2のTrust, Privacy, and Transparency原則に沿って、Settingsにデータリクエストの説明サーフェスを追加した。
削除、エクスポート、訂正、同意見直しの導線を将来実装する前に、対象範囲と安全条件を明確にした。

## Implementation Notes

- `DataRequestCopyService`を追加した。
- Settingsに`データリクエスト`カードを追加した。
- データエクスポート、データ削除リクエスト、訂正リクエスト、同意の見直しを表示する。
- 削除・エクスポートは無料の基本機能として扱う安全条件を明記した。
- 実データ削除、エクスポート生成、同意保存、問い合わせ送信はまだ実装していない。

## Acceptance

- Settingsでデータリクエストの種類を確認できる。
- Quest、Mission、Trail、Arc Memory、Profile、Media、Quest Supportなどの対象範囲が表示される。
- 削除・エクスポートを意図的に難しくしない方針が見える。
- 実データのmutationは行わない。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

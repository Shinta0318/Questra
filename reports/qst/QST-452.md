# QST-452 Tool Continuation Multi-turn Cost Attribution Drill

## Status

Completed locally. Hosted flag activation and PostgreSQL drill remain external evidence.

## Goal

Stateless Function Callingの複数turn、fallback、thinking、grounding、tool resultを、本文を保存せず一つの利用量へ欠落・重複なく帰属させる。

## Implementation

- 一つの利用者操作にcontinuation runを作り、provider呼び出しごとのsettled reservationとreceiptをturnへ結合した。
- 各turnのinput/output token、grounding query、thinking level、attempted／settled model、costだけを保存した。
- 最終化時にturn合計とorchestrator合計が完全一致しないrunを拒否した。
- fallback前後のmodel列を順序付きで保持し、最後の試行modelとsettled receiptの一致を必須にした。
- timeout、cancel、tool/provider/attribution failureをallowlist reasonで閉じ、同じ失敗やturn再送を冪等化した。
- 最大turnを初回provider呼び出し込み5件と定義し、DBの`turn_number 0..4`へ合わせた。
- prompt、response、interaction history、tool引数、tool result本文をcost evidenceへ保存しない契約を追加した。
- Feature Flagを既定OFFとし、Hosted drill完了前の有効化を禁止した。

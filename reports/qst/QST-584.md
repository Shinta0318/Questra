# QST-584 Candidate-Wide Secret Scan Inventory

Status: In Progress (local contract only)

## Finding

The candidate preflight scanned only four runtime/workflow directories. Tests, migrations, tools, QST reports, and other candidate text could carry a secret while the preflight still passed. The Git dirty count also collapsed untracked directories into one entry, obscuring the size of the candidate work.

## Change

- Enumerate Git-tracked and non-ignored untracked files with NUL-delimited paths, then scan every decodable UTF-8 text file regardless of directory. Binary and ignored files remain outside this text scan.
- Reject known text files that exceed the scan limit, are not UTF-8, contain binary data, or are symlinks, rather than silently treating them as inspected.
- Report only a path for a potential secret, never its value. Count untracked files individually in the development-mode dirty summary.
- Add a disposable Git-fixture regression test for tracked documentation, untracked reports, ignored files, and secret-value redaction. Run it in the release gate before the candidate preflight.

## Verification

- `dart run tools/qst/verify_candidate_preflight_test.dart`: passed.
- `dart run tools/qst/verify_candidate_preflight.dart`: passed in development mode, scanning 1,736 text files and reporting 340 dirty entries after this QST's files were added. Before this change the same command scanned 393 files and reported 306 collapsed entries.
- `dart analyze` on the preflight and fixture test: no issues. `dart run tools/qst/verify_backlog_ssot.dart`: 530 IDs passed. The related Hosted AI probe tests: 9 passed.
- The existing QST-269 VM journey test passed four scenarios on the current worktree. The browser/device and Hosted paths were not exercised by that test.
- CI execution of the new test, a clean candidate, and a Hosted deployment remain unverified.

## Boundary

This is a pattern-based candidate preflight, not a complete secret or privacy audit. Ignored files and binaries require separate handling, and the project still has a dirty worktree. A successful development-mode scan must not be promoted to a release approval. External Beta remains **NO-GO**.

# QST-460 Trail Parent Navigation

## Goal

Trailに表示されたQuest／Missionの紐づけを、確認だけでなく親詳細へ戻る実用的な導線にする。

## Implementation

- TrailカードのQuestチップからQuest詳細へ遷移できるようにした。
- Missionチップから、そのQuest配下のMission詳細へ遷移できるようにした。
- 作成／編集sheet内のbreadcrumbは誤遷移を避けるため表示専用を維持した。
- 操作可能なチップだけbutton semanticsと「〜を開く」の読み上げを追加した。
- 長い名前、2行省略、既存の階層表示を維持した。

# QST-482 Trail Draft Context Conflict Guard

## Goal

保存中のTrail下書きと、今回開いたQuest航路が異なる場合に、既存下書きを無言で無視・上書きしない。

## Implementation

- 呼出contextと下書きのQuest／Mission不一致を競合として保持する。
- 競合中は新しい入力のsecure draft保存を停止する。
- 通常のQuest選択式composerでは「下書きを開く」と「破棄してこの航路で続ける」を提示する。
- Taskなど固定parentのcomposerでは、既存下書きを残して閉じる選択肢を提供する。
- 下書きを開いた場合は元のQuest、Mission、本文、詳細表示状態を復元する。
- 明示破棄後は新しいdraft IDで現在の航路を継続する。

## External boundary

競合下書きは端末内の同一ownerに限定される。複数端末間のdraft同期やmergeは本QSTの対象外とする。

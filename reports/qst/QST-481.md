# QST-481 Trail Mission Creation Return Contract

## Goal

Trail作成中に対象QuestへMissionがない場合、Missionを追加した後で同じQuestを保持したTrail作成へ安全に戻れるようにする。

## Implementation

- `Trail -> Quest詳細 -> Mission作成 -> Trail作成`の戻り先契約を追加した。
- 戻り先は同じQuest IDを持つ内部`/trail?...&create=1`だけに限定した。
- 外部URL、別Quest、作成指定のないURLは拒否し、通常のQuest詳細操作へ影響させない。
- Mission作成成功時だけ戻り、キャンセルまたは保存失敗時はQuest詳細に留まる。
- Trail routeはTask親がなくても有効なQuest scopeがあれば作成Modalを開く。
- 戻った作成ModalはQuestを選択済みにし、利用者が対応Missionを選べる状態にした。

## External boundary

Mission自体のAI生成やMission作成時のTrail下書き引継ぎはこの契約に含めない。戻り先は内部Trail composerへ限定し、任意URLへのredirectには利用しない。

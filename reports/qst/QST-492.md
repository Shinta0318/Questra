# QST-492 Trail Parent Navigation Touch Target

## Goal

Trailカードから親Quest／Missionへ戻る階層chipを、指や支援入力でも安定して操作できるサイズにする。

## Implementation

- navigation可能な階層chipへ44pxの最小高さを追加した。
- InkWell自体が制約内を占有し、見た目より広い領域でタップできるようにした。
- 既存のbutton semanticsと親名の読み上げを維持した。
- 保存先previewの非interactive chipにはタップ制約を適用せず、意味のないbutton扱いを追加していない。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_492_trail_parent_touch_target_test.dart`

## Validation

- Parent navigation and touch target regression: 3 tests passed.

## External boundary

物理端末での片手操作、Switch Access、TalkBack focus ringはcandidate-bound実機証跡が必要である。

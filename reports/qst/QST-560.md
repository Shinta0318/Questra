Status: In Progress / local Web verified; Android assistive technology and Hosted success pending

- Date: 2026-10-09 (Asia/Tokyo)

- Source: a 390px connected-preview screenshot showed dark red `ColorScheme.error` text directly on the deep-navy login screen. The same pattern occurred in signup, forgot/reset password, and confirmation-help screens. This is a visibility defect even though QST-548 had already made entered field text legible.

## Change

`AuthErrorNotice` uses the existing notification-surface, text, and error-accent tokens in all five authentication forms. It wraps long messages, has an icon so meaning is not color-only, and exposes a live region. It does not alter Auth state, error classification, lockout behavior, mail, Supabase calls, or persistence.

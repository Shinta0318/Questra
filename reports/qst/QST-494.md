# QST-494 Trail Quest Selector Journey Ordering

## Goal

Trail作成時に現在進めているQuestをすぐ選べるよう、Quest候補を旅の状態に沿って安定した順序で表示する。

## Implementation

- Quest候補を進行中、下書き、完了の順に並べた。
- 同じ状態のQuestはタイトル順で安定して表示する。
- 完了Questは選択可能なまま、ラベルへ「（完了）」を付けた。
- archived Questを候補から除外する既存契約を維持した。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_494_trail_quest_selector_order_test.dart`

## Validation

- Trail Quest selector journey ordering: 1 test passed.

## External boundary

本QSTは候補の表示順だけを変更する。Quest status、Trail親ID、保存処理、RLS契約は変更しない。

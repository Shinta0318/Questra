# QST-146 Consent Purpose Registry

## Summary

Master Spec v2の「同意は具体的、理解可能、目的別、撤回可能」という原則に沿って、目的別同意カテゴリのRegistryを追加した。
包括同意で個別Questデータを別目的へ転用しないための前段として、Settingsに目的別同意カテゴリを表示する。

## Implementation Notes

- `ConsentPurposeRegistryService`を追加した。
- Quest支援、プロダクト改善分析、Arc品質改善、外部連携の4カテゴリを定義した。
- Settingsに`目的別の同意`カードを追加した。
- 各カテゴリに対象データ範囲、将来状態、撤回可能性を持たせた。
- 同意保存、opt-in/out mutation、外部連携は実装していない。

## Acceptance

- Settingsで目的別の同意カテゴリを確認できる。
- Quest Support、分析、Arc品質改善、外部連携が分離されている。
- 包括同意ではなく、目的別同意の原則が見える。
- 撤回可能性と無断転用禁止のガードレールが見える。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

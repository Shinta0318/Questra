## Change

`run_mock.ps1 -Offline` now passes an explicit auto-entry flag. `SupabaseConfig` enables it only when there is no Supabase configuration, local persistence is allowed, and the build is not release mode. `AuthController` creates the existing local preview profile at startup so protected deep links, including `/#/guild`, no longer redirect to login. The connected launcher does not set the flag and continues to require normal authentication.

Guild's offline route shows its search and honest empty state instead of a pilot gate. It clearly labels the offline limitation; the repository remains null, so publication, copying, and public feed retrieval are unavailable. The section picker received explicit foreground/background colors and text-only labels after the initial real-browser view showed unreadable, cramped labels.

## Implementation

- Gemini Interactions呼び出し前にservice-role RPCで原価枠を予約する。
- 成功時はProviderの実input/output tokenで一度だけ精算する。
- timeout、schema不正、Provider失敗時は予約を冪等に解放する。
- 同一user/operation/idempotency keyの再実行と並列呼び出しをDBで拒否する。
- 月次request/cost、1分間user/network abuse limitをatomic transactionで検証する。
- operation別kill switchを追加し、無効時はProviderを呼ばない。
- raw prompt、raw response、IP原文を台帳へ保存しない。ネットワーク制御にはsalt付きSHA-256のみを利用する。
- Token usageが欠落したProvider応答は成功扱いせず、計画の保存をfail closedにする。
- quota不足、停止中、台帳障害を区別し、入力保持、後で再試行、手動Mission追加を案内する。

## Data Contract

- `ai_operation_controls`: operation別kill switch。
- `ai_model_cost_rates`: provider/model/effective date別のversioned USD micro rate。
- `ai_budget_reservations`: reserve/settle/release、Token、原価、trace、匿名化abuse key。
- `ai_usage_counters`: reserved/settled countとreserved/actual costの月次集計。
- `ai_usage_cost_daily`: model/operation別Token、実原価、admission p95の運用ビュー。
- `ai_budget_alerts`: request/cost/rate/kill switch拒否の重複抑止付き監査記録。
- `reserve_ai_usage_budget`: advisory lock付きadmission。
- `settle_ai_usage_budget`: 実Tokenによる一度限りの精算。
- `release_ai_usage_budget`: 失敗時の冪等解放。

価格は2026-08-24確認時点のGoogle公式Gemini API pricingをversioned rateとして登録した。`gemini-3.6-flash`の期間限定価格には`valid_until`を設定し、期限切れ後に古い単価で通さない。

## Security Review

- reserve/settle/release RPCは`service_role`だけが実行できる。
- Flutterまたはauthenticated clientから任意user IDを指定できない。
- RLSにより利用者は本人のmetadata ledgerだけを参照できる。
- DB advisory lockとunique keyの両方でparallel burst/replayを防止する。
- 原価ログには会話本文、Quest本文、個人情報、raw IPを含めない。

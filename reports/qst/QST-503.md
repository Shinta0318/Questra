# QST-503 Canonical Navigation Return Contract Closure

## Summary

Primary Navigationと設定系画面のreturn contractを現在の実装へ揃えた。
QST-321は古いMission主タブ前提を含むため、本QSTで置き換えた。

## Changes

- Primary NavigationをHome、Quest、Arc、Trail、Profileとして正本化した。
- MissionとTaskをQuest branch内の文脈画面として明記した。
- stackがある場合はpopし、直リンク時は安全な親へ戻す共通buttonを追加した。
- Settings、Settings section、Feedback、Data Rights、Arc Memory、Guildへ適用した。
- direct routeとpush routeのWidget Testを追加した。

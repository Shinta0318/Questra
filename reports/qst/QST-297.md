# QST-297 Arc Clarification State Machine

## Status

`Completed`

Arcの確認質問とQuest確定を排他的な状態へ分離し、ユーザーが質問へ回答中に
「この航路をQuestにする」CTAが先に現れないようにした。

## Implemented

- Arc Chat responseへ最大3件の型付き`QuestClarificationQuestion`を追加した。
- `ArcQuestClarificationSession`が現在の質問、回答済み件数、完了状態を保持する。
- 確認中はQuest suggestion cardと通常Quick Actionを表示しない。
- 1回答ごとに次の重要質問へ進み、全回答後だけQuest確認CTAを表示する。
- 回答はQuest suggestionの`sourceInput`と`description`へ航路条件として引き継ぐ。
- 期限を含む明確な願いは不要な質問を省略し、すぐ確認可能にする。
- Safety判定が許可しない入力ではsessionとsuggestionを破棄する。

## State Contract

```text
discovery
  -> clarifying (1..3 material questions)
  -> confirmable (all required answers captured)
  -> Quest confirmation
```

`clarifying`中に`confirmable`のCTAを同時表示しない。

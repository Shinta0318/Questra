# QST-350 Quest Branch IA and Accessibility Closure

## Status

Implemented locally for static and automated gates. Physical Android evidence
is still required before external Beta.

## Summary

Added a local accessibility release gate, removed text-scale-canceling bottom
navigation labels, and expanded responsive smoke coverage to include a 320px
compact viewport. The gate explicitly separates local static verification from
physical TalkBack/IME/large-text evidence so release readiness is not
overstated.

- `tools/qst/verify_accessibility_release_gate.dart`
- `docs/product/accessibility_release_gate.md`

## Acceptance Notes

- Bottom navigation no longer uses `FittedBox` or `BoxFit.scaleDown`.
- Navigation labels preserve the user's text scale and use ellipsis when needed.
- Responsive viewport matrix now includes a 320px compact case.
- Static release gate checks Master Spec, Design Bible, IME test coverage,
  bottom navigation semantics, responsive compact evidence, and forbidden
  scale-down UI patterns.
- Physical evidence mode requires candidate-bound TalkBack, Japanese IME,
  200% text, and physical Android evidence before external Beta.

# QST-295 Remove Template-Based Quest Variants

Status: Completed

## Summary

「近いQuestの形」と固定的な文字列変換を廃止し、Arcが願いを意味解析してQuestを確認してからMission Planningへ進む構造へ変更した。明確な願いでは候補を表示せず、不足情報がある場合だけ最大3問、達成方向が実質的に分かれる場合だけ最大3案を返す。

## Changes

- `FlexibleQuestProposalService` と固定suffix候補を削除。
- Arc画面から「近いQuestの形」「選んだ案を組み合わせる」を削除。
- `QuestIntentResolutionService` を追加し、Local semantic resolverとSupabase resolverを同じ型へ統一。
- 「Arcと一緒にQuestを整理 → ArcがまとめたQuest → このQuestで進む → Mission Planning」の承認順序を追加。
- 旅行・学習・習慣・明確な達成条件に応じて確認質問を変えるローカル判定を追加。
- Edge FunctionへStructured Outputの `quest_intent` modeを追加し、候補ゼロを正式に許可。
- 14種類のQuest Typeを内部分類し、Quest DNAの `quest_type` として保存可能にした。
- 単純なQuestではMission 1件も許容し、Mission件数を3件以上へ強制する制約を解除。
- 旧Quest DNAは不足した `quest_type` を `未評価` として読み込むため互換性を維持。

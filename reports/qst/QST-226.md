# QST-226 Personal Context-Aware Planning

Status: In Progress

- Added consent-gated planning context for time, budget, location, experience, resources, and preferences.
- Unconsented context serializes only its consent state and never includes raw conversation content.
- Added a Settings control center with an explicit Arc planning opt-in. Turning it off prevents the planning fields from entering the Arc Quest Guide request.
- Added secure local persistence and owner-scoped Supabase persistence for consent and explicitly entered planning conditions.
- Added client and Edge Function bounds. The Edge Function discards planning context unless `consent_granted` is exactly `true`.
- Connected consented context to both Quest Detail guide generation and the Arc-led Quest creation flow.
- Local fallback guidance now reflects explicitly consented weekly capacity and experience instead of silently inferring them.

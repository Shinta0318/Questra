# QST-289 Arc Memory Task Event Integration

## Status

`ImplementedDeploymentRLSEvidencePending`

Task開始・完了・延期を、同意済みのユーザーに限ってArc Memoryへ関連づける
Flutter/DB実装を完了した。新migrationの実Supabase配備と二アカウントRLS実証は未実施。

## Implemented

- `task_memory`と`task_started`、`task_completed`、`task_rescheduled`を追加した。
- Arc MemoryがTask、親Mission、親Questを同時に参照できるようにした。
- Arcパーソナライズ同意がない場合はTaskイベントを保存しない。
- Task保存成功後だけMemory抽出を行い、Memory失敗でTask保存を壊さない。
- Task削除時に関連Memoryを削除するDB cascadeとRepository操作を追加した。
- DB triggerでTaskとMemoryのowner、Quest、Mission一致を強制した。
- Task Memory取得は既存の件数・重要度・機微情報フィルターを継承する。
- 日本語本文を消していた既存dedupe正規化を修正した。

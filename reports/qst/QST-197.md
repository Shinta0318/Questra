# QST-197 Trail and Guild Beta Scope Decision

## Result

Initial BetaではTrailを有効化し、Guildを延期する。TrailはQuest -> Mission -> TrailというQuestraの中核ループに必要であり、Primary Navigationへ復帰した。GuildはDiscovery、参加、投稿、Moderation、RLSの実環境証跡が揃うまで、ソースとデータを保持したままComing Soonとして扱う。

## Changes

- Bottom Navigationを`ホーム / Quest / Arc / Trail / プロフィール`へ統一した。
- `/trail`をShell配下の実装済み`TrailScreen`へ接続した。
- `/guild`をShell外の共通Coming Soon画面へ移し、未完成操作をPrimary Navigationから除外した。
- Beta Readiness Report、Release Notes、Go/No-Go checklist、Release Notes verifierを同じ判断へ揃えた。
- NavigationとRouterのwidget testをTrail有効・Guild延期の契約へ更新した。

## Beta Gates

- Trailの画像アップロード、差し替え、削除、Storage永続化はQST-204でAndroid/Web実機証跡を取得する。
- Guildの再有効化にはQST-199のRLS証跡、QST-203のRepository / Moderation、QST-214〜220のDiscovery Epicに必要な公開境界を満たすことが必要。

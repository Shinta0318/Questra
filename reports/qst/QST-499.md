# QST-499 Trail Journey Performance Budget

## Goal

Trailが増えてもQuest／Mission filter、一覧取得、cursor paginationが無制限に重くならない性能契約を定義する。

## Implementation

- Quest／Mission filterとID収集を1パスで行う`projectTrailJourney`を追加した。
- Trail画面はprojection結果を一覧、Media、Highlightへ共有する。
- ローカル表示対象を400件、projectionを16msの予算として定義した。
- Repositoryの既存40件page limitとowner scopeを回帰テストした。
- performance verifierへTrail projection、性能定数、owner＋Quest／Mission cursor indexを追加した。

## Validation

- Trail performance、filter、cursor pagination regression: 7 tests passed.
- Performance readiness verifier: passed; 7 Arc assets and 10 performance-sensitive files checked.

## Performance boundary

16msはWidget test環境での純粋projection予算であり、実機frame timingの代替ではない。Hosted query latency、画像decode、物理端末scroll 60fpsはcandidate SHA固定のprofile evidenceで別途確認する。

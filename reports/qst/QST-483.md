# QST-483 Trail Newly Created Mission Selection

## Goal

Trail作成から不足Missionを追加した利用者が、戻った直後に同じMissionを探し直さず記録へ進めるようにする。

## Implementation

- Mission作成dialogの結果をbooleanではなく作成済み`Mission`として返すようにした。
- Trailへ戻るURLへ作成済みMission IDを追加した。
- 既存のTrail route契約を使い、対象Questと新規Missionをcomposerへ事前選択する。
- キャンセル、validation失敗、保存例外ではMission結果を返さず、Trailへ遷移しない。
- Trail以外からQuest詳細を開いた通常のMission作成は従来どおり同じ画面に留まる。

- QST-481 / QST-483 route and widget regression: 4 tests passed.

## External boundary

AI生成で複数Mission候補を採用した場合は、利用者がTrailへ紐づけるMissionを明示選択する。自動選択はこの導線で単一Missionを手動作成した場合だけに限定する。

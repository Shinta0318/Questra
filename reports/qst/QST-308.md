# QST-308 Arc Draft Screen Integration Report

## Status

Completed on 2026-08-09.

## Summary

Arcのsecure draftを実画面へ接続した。認証済みユーザーごとに会話、clarificationの質問と回答、未確定のQuest案を暗号化ストレージへ保存し、再起動後に相談を再開できる。

## Implementation

- draft payloadをversion 2へ拡張し、version 1の会話データも読み込み可能にした。
- Arc画面の状態変化ごとにdraftを直列保存し、古いwriteがdiscard後に復活しないようにした。
- user IDごとのkey partitionとpayload owner照合を維持した。
- 認証ユーザー切替時は前ユーザーの状態を画面から除去し、新しい所有者のdraftだけを復元する。
- 復元時に「前回の相談の続き」を表示し、ヘッダーまたはカードから明示的に破棄できるようにした。
- Quest確定後は保存済みdraftを削除し、同じQuest案の再作成を防止した。
- 14日を超えたdraft、壊れたpayload、owner不一致payloadは画面へ渡さない。

# QST-338 External Release Truth and Authenticated Router Guard Report

## Status

ImplementedExternalEvidencePending

実装とローカル自動検証は完了した。Web/Android実機でのdeep-link、session expiry、cold auth p95の外部証跡はQST-343およびQST-350のrelease evidenceへ引き継ぐ。

## Implemented

- GoRouterへ認証・onboarding・password recoveryの共通redirectを追加した。
- 未認証で保護routeを開いた場合、Loginへ遷移し、認証後に安全な相対URLへ復帰する。
- session復元中も元のdeep-linkを保持し、外部URL、authority付きURL、認証画面へのcontinuationを拒否する。
- session復元失敗時は個人画面を描画せず、再確認またはログアウトを選べる。
- Supabaseのsigned-out eventでローカルprofileを破棄する。
- production/releaseではSupabase未設定時のlocal/mock persistenceを禁止した。
- development releaseでlocal persistenceを使う場合は、`APP_ENVIRONMENT=development`と`ALLOW_MOCK_PERSISTENCE=true`の両方を必須にした。
- local persistence利用時はSplashと認証後の全画面へ「開発用データ / この端末内だけに保存」を表示する。
- `RELEASE_CAPABILITIES.yaml`を追加し、GuildとPremiumを未出荷として明示した。
- Store draftからGuildが利用可能であるように読める表現を削除した。
- Quest未選択時の「Quest詳細へ」自己遷移を「ArcとQuestを考える」へ変更した。

# QST-463 Trail Contextual Create

## Goal

表示中のQuest／Mission航路からTrailを残す際に、同じ親を再選択する負担と誤紐づけを減らす。

## Implementation

- Trail作成sheetへ初期Quest IDとMission IDを渡せるようにした。
- Missionまで絞り込み中はQuestとMissionを選択済みで開く。
- Questだけ絞り込み中はQuestを選択済みにし、Missionはユーザーが選べる状態を維持した。
- Task起点の固定親contextは従来どおりbreadcrumb表示とし、手動変更を許可しない。
- 選択値は既存のactive Quest／removedでないMission検証を通すため、古いIDを保存へ利用しない。

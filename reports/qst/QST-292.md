# QST-292 Long Route Task Performance Pass

## Status

`Completed`

多数のMissionとTaskを持つ長期Questで、親ごとに全件走査を繰り返す処理と
Quest詳細で全Mission Cardを一括構築する処理を抑えた。

## Implemented

- `GroupedCollectionIndex`を追加し、Mission別TaskとQuest別Missionを1回の線形走査で索引化した。
- Home、Mission一覧、Quest詳細の繰り返しfilterを索引参照へ置き換えた。
- Quest詳細のMission previewを12件に制限し、残件は「航路全体を見る」へ誘導した。
- Task一覧取得を200件、Mission単位取得を50件へ共通定数で明示した。
- 12,000 Task / 80 Mission fixtureの索引構築を100ms以内とする回帰予算を追加した。
- 長期航路の取得上限と描画上限をテストで固定した。

## Complexity Review

| Surface | Before | After |
|---|---|---|
| Mission list Task lookup | Mission数 x 全Task走査 | 全Task 1回 + O(1) group lookup |
| Quest detail Task lookup | Mission数 x 全Task走査 | 全Task 1回 + O(1) group lookup |
| Home Quest progress lookup | Questごとに全Mission走査 | 全Mission 1回 + grouped lookup |
| Quest detail card build | 全Missionを一括build | 最大12件、全件は専用航路画面 |

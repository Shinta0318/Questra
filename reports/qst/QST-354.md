# QST-354 Guild Quest Library Controlled Pilot

## Status

Implemented as a controlled-pilot foundation. The pilot is disabled unless an
operator explicitly enables an authenticated user in `guild_pilot_members`.

## Outcome

Guild adoption now creates a real owner-private Quest, optional outcome
Missions, and a first ready Task in one database transaction. Repeated requests
with the same idempotency key return the original Quest. The approved source
snapshot is never mutated.

## Safety and Data Boundaries

- Discovery reads and copy RPCs require an enabled Pilot membership.
- Server-side keyset pagination replaces the local newest-40 query.
- Published Mission snapshots capture action, completion condition, and output
  before they can become copy sources.
- Copy events retain source snapshot version and attribution without exposing
  adopter progress to the source author.
- Owner-scoped moderation appeals are persisted for operational review.

# QST-106 Menu Widget Refactor

## Status

Done

## Summary

Added reusable Questra action and popup menu components, then replaced repeated
button and hand-built menu patterns across core journey screens.

## Implementation

- Added `QuestraActionButton` with a consistent accessible touch target.
- Added typed `QuestraMenuItem<T>` definitions.
- Added `QuestraPopupMenu<T>` with icon, disabled, and destructive states.
- Replaced repeated outlined actions in Quest and Mission surfaces.
- Replaced the hand-built Trail popup menu with the shared typed menu.
- Localized Trail action labels to Japanese.
- Styled the Trail delete action as destructive without changing behavior.

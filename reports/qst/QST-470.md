# QST-470 Trail Update Rejection Feedback

## Goal

Trail編集が親整合性policyで拒否された場合と通信保存に失敗した場合を区別し、入力を失わず次の行動を案内する。

## Implementation

- Trail更新結果を`saved`、`rejected`、`failed`へ型分けした。
- 親policy拒否ではQuestとMissionの再選択を案内する。
- 対象Trailが見つからない場合は画面更新を案内する。
- 通信／Repository失敗では入力保持と再試行を案内する。
- Edit sheetのlive regionへ結果メッセージを表示する。
- 既存のbool更新APIは互換ラッパーとして維持した。

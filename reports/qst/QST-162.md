# QST-162 Dual Account Persistence Acceptance

## Status

**In Progress: secure runner ready; dedicated Beta account execution pending**

Profile、Quest、Mission、Arc MemoryをAccount Aで作成・再ログイン後に再取得し、Account Bから
private journey dataが見えないことを確認するクラウド受入runnerを追加した。認証情報は環境変数だけで
受け取り、証跡へ値を保存しない。

## Implemented

- 二つの既存Betaアカウントをpassword grantで認証するDart runner
- Account Aの再ログイン後に4領域を再取得する永続化検査
- Account BによるQuest、Mission、Arc Memoryの不可視性検査
- UUIDを固定せず、成功・失敗後に試験journey dataを削除するcleanup
- candidate commitとproject refだけを持つsanitized evidence contract
- credential、email、anon key、private contentの混入を拒否するverifier

## Remaining Evidence

専用BetaアカウントA/Bの認証情報をローカル環境変数へ設定してrunnerを実行する。値をコマンド履歴、
repository、Reportへ書かない。実行後に`--require-cloud` verifierが成功するまで完了扱いにしない。

## Validation

- `dart format tools/qst/run_dual_account_persistence.dart tools/qst/verify_dual_account_persistence.dart`
- `dart analyze tools/qst/run_dual_account_persistence.dart tools/qst/verify_dual_account_persistence.dart`
- `dart run tools/qst/verify_dual_account_persistence.dart`
- `dart run tools/qst/verify_dual_account_persistence.dart --require-cloud`は実アカウント実行前に失敗すること

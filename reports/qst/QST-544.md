# QST-544 Budgeted Gemini Path for Direct Arc Text Generation

Status: In Progress / local_partial

## Finding

QST-543 closes the anonymous-user boundary locally, but the seven direct Arc/Gemini handlers still reached the legacy shared text provider without the QST-342 atomic AI budget reservation. A signed-in account could therefore consume model quota outside the existing admission controls. Arc Chat and Mission Research also call a separate grounded-search provider; that path is outside this QST and remains a release blocker.

## Local implementation

- The shared direct text provider now delegates Gemini calls to the existing `callGeminiInteraction` adapter. That adapter reserves budget before the provider call, records provider execution, and settles real token usage. It fails closed when budget service, usage, or settlement is unavailable.
- Direct features map to existing model roles. Arc chat/advice/moderation use the `arc_consultation` budget operation; Mission generation uses `basic_mission_planning`. The source type returned to direct callers remains `gemini_interactions`.
- The previous standalone Gemini and OpenAI request paths were removed from the shared text provider. `AI_PROVIDER=openai` now returns no AI result until it has a budgeted provider implementation. The Beta bootstrap documentation reflects this deliberate restriction.
- No hosted migration or function deployment was performed. The local connected preview may show fallback until the budget RPCs and functions are deployed to the same candidate.

## Verification

- `node --test supabase/functions/_shared/direct_ai_budget.test.mjs`: checks budget denial, missing budget configuration, successful reserve/provider/receipt/settle ordering and actual usage, OpenAI fail-closed, and missing-usage fail-closed without real AI or database traffic.
- `node --test supabase/functions/_shared/ai_auth.test.mjs`: confirms the separate user boundary still rejects public-key-only calls.
- Hosted budget admission, live Gemini usage, parallel quota enforcement, and grounded-search cost have not been verified. External Beta remains NO-GO.

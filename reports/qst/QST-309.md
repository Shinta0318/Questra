# QST-309 Data Rights Reauthentication and Worker Report

## Status

Implemented locally on 2026-08-09. Cloud deployment remains a release operation.

## Implementation

- Account deletion requires an authentication token issued within 10 minutes.
- The app reauthenticates with the current password before submitting deletion.
- Deletion is scheduled after a 72-hour cancellation window.
- Owners can cancel only their own scheduled request before the deadline.
- Idempotency keys and active-request detection prevent duplicate deletion requests.
- A service-role-only RPC claims due requests with `FOR UPDATE SKIP LOCKED`.
- Worker failures retry after one hour, with a maximum of five claims.
- The Edge Function requires an independent worker secret and performs Supabase Auth soft deletion.
- Request status and cancellation are available from the Data Rights screen.
- The legacy RPC overload without reauthentication was removed.

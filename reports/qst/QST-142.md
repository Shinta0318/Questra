# QST-142 Enterprise Support Boundary UI

## Summary

Master Spec v2のEnterprise Platform / Quest Support Modelに沿って、MVP/Betaで企業機能を複雑に実装せず、将来の企業支援を透明に扱うための境界UIを追加した。
企業支援は広告ではなく、ユーザーのQuest前進を助けるものとして扱う前提をQuest詳細に表示する。

## Implementation Notes

- `QuestSupportBoundaryService`を追加した。
- Master Specの4役割であるSponsor、Coach、Partner、Official Event Hostをモデル化した。
- Betaでは`isActive: false`とし、スポンサー接続や企業データ取得は行わない。
- Quest詳細に`Quest支援の透明性`カードを追加し、表示前に必要な透明性と守る境界を明示した。
- Supabase、広告配信、課金、企業アカウント機能は追加していない。

## Acceptance

- 4つのEnterprise支援役割をコード上で表現できる。
- Betaでは未接続であることを明示している。
- Quest詳細で透明性要件とガードレールが確認できる。
- Arcの信頼を広告化しない境界が表示される。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

# QST-138 Challenge Graph Insight Layer

## Summary

Challenge Graph Previewを、数値表示だけでなくArcが次の一歩を案内できる洞察レイヤーへ拡張した。
既存のQuest、Mission、Trailだけを使い、Mission不足、Trail不足、Reflection不足、順調状態を判定する。

## Implementation Notes

- `ChallengeGraphInsight` and `ChallengeGraphInsightType`を追加した。
- `insightsForQuest`で既存のQuest文脈から最大3件の優先洞察を返す。
- Quest詳細に`Arc Graph Insight`を追加し、Graphの不足接続と次の行動を表示する。
- Supabase、AI接続、Graph DBは追加していない。

## Acceptance

- Challenge GraphがQuest、Mission、Trail状態から洞察を生成できる。
- MissionがないQuestではMission作成を促す。
- Trailが育っていてReflectionがない場合は振り返りを促す。
- Quest詳細でArc Graph Insightが表示される。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

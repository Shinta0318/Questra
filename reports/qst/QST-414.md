# QST-414 First Run and Authentication Plain-Language UX

Status: **InProgress (local implementation verified, external evidence pending)**

## Summary

Splash、Login、Signup、パスワード再設定の情報階層を見直した。初回画面では「ログイン」と「初めての方」を直接選べ、LoginとSignupでは共通の切替を最初に表示する。航海比喩を主操作から外し、認証操作を短い日本語で示した。

## Implemented

- `AUTH_PLAIN_LANGUAGE_V2`を追加し、モバイルのArc Heroを270pxから196pxへ抑えた。
- Splashの価値説明を一文に絞り、ログインと初めての方の2入口を表示した。
- LoginとSignupへ共通の`AuthEntrySwitcher`を追加した。
- Loginの登録入口をフォーム下部から初期表示内へ移した。
- Signup、forgot、resetの見出しと主ボタンを登録・再設定の直接表現へ変更した。
- パスワード再設定前に、登録メールアドレスが必要な条件を明示した。
- 文字2倍で発生したHero、Questra wordmark、ログイン区切りのoverflowを解消した。
- 規約確認済み表示の`Privacy`と`AI処理`を、日本語のプライバシーとArcの生成機能へ変更した。

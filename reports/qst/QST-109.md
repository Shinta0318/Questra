# QST-109 Quick Action Menu

## Summary

Questra-style Quick Action Menuを共通Shellに追加し、主要画面からQuest作成、Trail記録、Arc、Guild相談へすばやく到達できるようにした。

## Master Spec Alignment

- Quest、Mission、Trailの循環を強める導線として実装した。
- Arcはユーザーの次の一歩を支える存在として扱い、AI assistant表現は使用していない。
- 課金、企業支援、複雑な新規バックエンド処理は追加していない。
- UIを混雑させないよう、主要アクションはFABからのボトムシートに集約した。

## Implementation Notes

- compact画面では丸いStar Map風FAB、expanded画面では`Star Map`ラベル付きFABを表示する。
- Quick Action Sheetの項目:
  - `Questを始める` -> `/quest/create`
  - `Trailを残す` -> `/trail`
  - `Arcと話す` -> `/arc`
  - `Guildへ相談` -> `/guild`
- TrailとGuildは既存画面内の作成・相談導線へ遷移し、QST-109では新しい保存処理やBackend接続を追加していない。

# QST-260 Mission Card UX Redesign and Quest Mission Task Visual Separation

## Status

AutomatedWebAndroidPassPhysicalAccessibilityPending

Missionカード、Mission編集、Mission詳細、Task詳細、分析イベント、単体・Widget・全体回帰テストは完了した。2026-08-09時点でWebとAndroid emulatorの自動E2EもPassしたが、物理端末Accessibilityと現行SHAの状態別visual evidenceが未完のため正式完了にはしていない。

## Implemented

- Quest詳細のMissionカード右側にあった縦アイコン列を廃止し、補助操作をMoreメニューへ集約した。
- Missionカードへ`MISSION`、必須Task完了数、Mission名、完了条件、次のTask、最大3件のメタ情報を表示した。
- 必須Task数を進捗の正本とし、Task未作成時だけMission進捗へフォールバックする判定を追加した。
- Taskと前提Missionの状態から`Taskを見る`、`次のTaskを始める`、`続きから`、`完了内容を見る`、`前提を確認`を自動選択するPrimary CTAを追加した。
- 既定表示は次のTask 1件に絞り、必要時だけカード内でTask一覧を展開できるようにした。
- Arc相談、Mission編集、Task見直し、再生成、期限変更、順番変更、任意切替、アーカイブ、削除をMoreメニューへ整理した。
- 削除は確認ダイアログを維持し、順番変更はドラッグ以外でも操作できるダイアログを追加した。
- 通常ユーザー向けMissionカードからAI confidenceと生成内部情報を除外した。
- Mission編集を`Missionの名前`、`このMissionで達成すること`、`Mission完了条件`、優先度、必須、期限へ変更した。
- Mission詳細とTask詳細へQuest / Mission / Taskの階層ラベルを追加し、成果と具体行動を視覚的に分離した。
- 44px以上の主操作、ツールチップ、Semantics、色以外の状態ラベルを適用した。
- QST指定のMissionカード・Task導線分析イベントをAnalytics Registryへ追加した。

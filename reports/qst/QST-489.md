# QST-489 Trail Filter Result Feedback

## Goal

Quest／MissionでTrailを絞り込んだ結果を、一覧の変化だけに頼らず理解できるようにする。

## Implementation

- Quest filterとMission filterへ読み上げ目的を追加した。
- filter適用中に「N件のTrailを表示」を追加した。
- 件数はlive regionで「絞り込み結果」として通知する。
- filter解除後は件数表示を取り除き、全Trailを再表示する。
- 既存のcompact 1 column／wide 2 column filter layoutは維持した。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_489_trail_filter_result_feedback_test.dart`

## Validation

- Filter result feedback: 1 test passed.
- QST-461 and QST-466 filter／URL regression: 4 tests passed during implementation.

## External boundary

大量Trailでの実ブラウザー読み上げ速度と物理端末TalkBackはcandidate-bound実機証跡が必要である。

# QST-443 AI Budget Reconciliation Operator Queue

## Status

Completed locally. Hosted operator drill remains external evidence.

## Goal

未解決のAI予算精算caseを、最小権限の登録済みoperatorが競合なくclaimし、個人情報を自由文へ残さず解決できる運用境界を作る。利用量補正はcase解決から分離し、二者承認とtransactionを必須にする。

## Implementation

- `service_role`かつ有効なoperatorだけが利用できるlease付きqueue claimを追加した。
- `FOR UPDATE SKIP LOCKED`で並行workerによる二重claimを防止した。
- claim、解放、解決、補正の各操作をallowlist reason codeで監査する。
- 既存の`resolution_note`を常にnullへ正規化し、operatorの自由文や個人情報を保存しない。
- AI利用量補正をrequest、別operatorのapprove/reject、approved requestのapplyへ分離した。
- Apply時にrequest、reservation、counterをlockし、stale snapshotと二重適用を拒否する。
- Queue metricsは件数、経過秒、SLA違反数だけを返し、利用者IDやその他の識別子を返さない。
- Operator evidenceを730日で削除できるbounded retention RPCを追加した。
- Hosted contract check、operator drill、非破壊rollback手順を文書化した。

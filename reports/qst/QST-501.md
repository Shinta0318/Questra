# QST-501 Profile Dark Journey Surface Alignment

## Goal

Profileだけが大型light cardの集合に見える状態を解消し、Home・Arc・Questと同じ静かな宇宙航路のsurfaceへ揃える。

## Implementation

- Account、Arc Bond、Navigator Rank、旅の現在地の4カードをdark paletteへ変更した。
- Rank label、Bond score、icon、progress backgroundの固定色をsurface `ColorScheme`へ置き換えた。
- 4カードへ安定したsemantic test keyを追加した。
- 機能、数値計算、ログイン／ログアウト、設定導線は変更していない。

## Validation

- Profile dark surface at 390px／200% text and shared surface contrast regression: 16 tests passed.

## UX assessment

明るい管理画面風カードから、QuestraのDeep Navyを基調とする連続した旅の情報面へ近づいた。Stardust、Bond、Navigator Rankは維持するが、派手なゲーム演出は追加していない。

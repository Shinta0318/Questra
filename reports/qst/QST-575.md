It checks the final migration version and presence of the three authentication functions before running the existing RLS and lockout SQL contracts. No `--linked` reset or remote database write was added.

The official [Supabase CLI reference](https://supabase.com/docs/reference/cli/supabase-migration-list), checked 2026-10-18, documents local migration history and pending `migration up`; the [local workflow guide](https://supabase.com/docs/guides/local-development/cli-workflows) distinguishes destructive linked reset from local reset. The exact CI command still requires execution on the pinned CLI version in this repository.

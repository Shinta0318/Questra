# QST-497 Trail Physical Accessibility Evidence Contract

## Goal

TrailのQuest -> Mission -> Trail導線を、物理AndroidのTalkBack、日本語IME、200%文字拡大を含むcandidate-bound証跡なしで合格扱いにしない。

## Implementation

- 既存の物理アクセシビリティ証跡へTrail固有の5シナリオを追加した。
- recorderは各シナリオへ`true`の明示確認がなければ証跡を生成しない。
- physical verifierは全シナリオが`passed`でなければrelease gateを通さない。
- 未実施の証跡は`pending_physical_execution`のまま維持した。
- 既存のcandidate SHA、clean worktree、実端末ADB、privacy review、artifact hash契約を変更していない。

## Required Trail scenarios

1. Questを選択し、そのQuestに属するMissionだけを選択できる。
2. Trail本文で日本語IME compositionが壊れない。
3. 200%文字拡大でも親選択と保存を完了できる。
4. TalkBackが親選択、保存状態、エラーを自然な順で読む。
5. 保存成功と親availability errorが色だけに依存しない。

## Validation

- QST-371／376／497 physical evidence contract tests: 8 passed.
- Physical accessibility evidence verifier: contract ready, execution pending.
- Accessibility release gate: local static contracts passed.

## External boundary

本QSTで完了したのは証跡契約と記録ツールであり、物理Android実行そのものではない。`docs/qst/PHYSICAL_ACCESSIBILITY_EVIDENCE.yaml`は引き続き`pending_physical_execution`で、External Betaの証拠には数えない。

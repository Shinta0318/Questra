# QST-490 Trail Draft Save Status

## Goal

Trail入力中に下書きが保存されたか分からない不安を減らし、失敗時も入力が画面に残っていることを明示する。

## Implementation

- draft状態へidle、saving、saved、failedを追加した。
- 入力後のdebounce開始時に「下書きを保存しています...」を表示する。
- secure storage成功時に「下書きを保存しました。」へ更新する。
- 失敗時は「入力は画面に残っています」と表示し、controller内容を変更しない。
- write versionを使い、古い非同期完了が新しい保存状態を上書きしないようにした。
- 状態copyをlive regionとして読み上げる。

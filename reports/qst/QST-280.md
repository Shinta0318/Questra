# QST-280 Home Today Task Journey Polish Report

## Result

Completed on 2026-08-08.

Home now presents one Task-centered next action with its parent Quest and
Mission context. Loading, read failure, completed-today, rest-day and no-Task
states each provide a deliberate next step without reverting to a second Task
list or a direct Mission completion shortcut.

## Changes

- Added an explicit Task load-state provider for loading, loaded and failed
  states.
- Prevented stale concurrent Task loads from replacing a newer owner snapshot.
- Added a pure Home today-journey resolver for actionable, completed and empty
  states.
- Replaced the mixed Task/Mission Home surface with one responsive Task card.
- Displayed the parent hierarchy as `Quest / Mission` context above the Task.
- Reduced the card to one primary command: start, open, retry, resume, inspect
  Mission, consult Arc or record a Trail.
- Changed an in-progress Task return state to `Taskを開く` instead of exposing a
  second completion shortcut on Home.
- Added compact-width and large-text semantics coverage.
- Removed the superseded private Home Mission list widgets.

## Remaining Boundary

Home keeps the Task mutation retry state in the active session, as established
by QST-277. Persisting that queue across app termination remains a separate
offline-first concern and is not implied by this Home presentation change.

# QST-155 Arc-led Quest Creation

## Summary

ArcをQuest作成の主導線にし、自然な言葉から複数のQuest候補を作成、編集、確認してから保存するフローを追加した。

- `apps/mobile/test/arc_quest_creation_service_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-155.md`

## Implementation Notes

- Arcの司令室に`ArcとQuestを考える`主要CTAを追加した。
- 自然言語入力から5件のQuest候補を生成し、再生成できるようにした。
- 候補名の編集、1件から7件までの追加・削除、ドラッグによる並べ替えに対応した。
- 明示的な確定操作まではQuest Controllerへ候補を渡さない。
- 確定時は空タイトルを除外し、既存のQuestモデルと保存Controllerを再利用する。
- 生成失敗時も入力を保持し、3件の手動編集候補へフォールバックする。
- 生成Serviceをinterfaceで分離し、将来のAI Provider接続時もUIと保存境界を維持できる構造にした。
- DB migration、既存テーブル、既存ユーザーデータは変更していない。

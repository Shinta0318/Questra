# QST-115 Accessibility Pass

## Summary

主要UIのタップターゲット、読み上げラベル、大きい文字での操作性を改善し、Beta前のアクセシビリティ基盤を強化した。

## Master Spec Alignment

- Beta品質方針に沿って、compact画面と大きい文字での主要フロー検証を強化した。
- Arc入口やQuestカードを、視覚だけでなく支援技術でも意味が伝わるUIとして補強した。
- UI/UX改善に限定し、Supabase、AI接続、保存境界は変更していない。
- ArcをAI assistantとは表現していない。

## Implementation Notes

- `QuestraAccessibility`を追加し、最小タップターゲットと快適タップターゲットの共通定数を定義した。
- Arc Floating Entryに48px以上の最小タップ領域を保証した。
- Quick Action Sheetの各アクションに56px以上の快適タップ領域を保証した。
- HomeとQuest一覧のQuestカードにSemanticsのbutton labelと進捗valueを追加した。
- 進捗バーはカード全体のSemantics valueに統合し、重複読み上げを避けた。
- テストでArc入口、Quick Action、QuestカードSemantics、大きい文字表示を固定した。

## Acceptance

- Major MVP screens remain usable with larger text and accessible tap targets: Done
- Arc Floating Entry has a 48px+ tap target: Done
- Quick Action items have 56px+ touch targets: Done
- Quest cards expose accessible labels and progress values: Done
- Story表現なし: Done
- ArcをAI assistantとして扱っていない: Done

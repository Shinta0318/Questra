# QST-436 Gemini Interactions Usage Settlement Contract

## Status

Validated / local verified

## Problem

Interactions API v1は`total_input_tokens`、`total_output_tokens`、
`total_thought_tokens`を返すが、Adapterは旧fieldだけを解析していた。このため正常なGemini
応答でもusage欠落として精算に失敗し、thinking費用も集計できなかった。

## Changes

- Interactions APIの正式なtotal系fieldを優先して解析する。
- visible outputとthinking tokenを合計してbillable outputとする。
- generated output、thinking、cached、tool useを別内訳でも保持する。
- generateContent系の旧fieldは移行互換経路として維持する。
- token値を0以上のsafe integerに限定する。

## Validation

- 公式例相当のinput 7、output 23、thought 49からbillable output 72を実行確認する。
- 負数と小数を拒否する実行確認を行う。
- Flutter contract testとBacklog SSOTを実行する。

## Source Basis

Google Gemini Interactions API v1 referenceのUsage契約と、Gemini pricingの
「output price includes thinking tokens」を参照した（2026-09-12確認）。

## Security and Privacy

token数だけを扱い、prompt、回答本文、ユーザー識別子を新しいusage内訳へ保存しない。

# QST-174 Quest Planning Template Matrix

## Status

Completed. Supabase Beta deployment and 50-case live evaluation completed.

## Goal

旅行だけに最適化されたQuest Guideを、学習・健康・仕事・創作・人間関係・生活など幅広い「やりたいこと」へ適応させる。Gemini無料枠へ到達した場合も、分野固有のMission品質を維持する。

## Scope

- 50種類のランダムなQuest評価ケースを作成する。
- Gemini生成とサーバー側フォールバックを同じ品質基準で評価する。
- カテゴリと題名・説明から計画テンプレートを自動選択する。
- テンプレートをGeminiプロンプトとフォールバックの両方で利用する。
- Supabase Betaへ配備し、同じ50件で再評価する。

## Planning Templates

1. 旅行・訪問
2. 学習・自己研鑽・資格
3. 健康・運動・生活習慣
4. 仕事・キャリア・副業
5. 創作・表現・発信
6. 家族・友人・人間関係
7. 暮らし・住まい・習慣
8. 家計・貯蓄・金融学習
9. 地域活動・コミュニティ・社会参加
10. 挑戦・スポーツ・アウトドア
11. プロダクト・発信・小規模事業
12. 自己成長・内面的な挑戦

Flutter、ポートフォリオ、ポッドキャスト、ニュースレター、オンラインショップなど、カテゴリより題名の手掛かりが強い複合Questはプロダクト航路を優先する。

## Evaluation Matrix

50件の内訳は、旅行4、学習6、健康6、仕事5、創作5、家族・人間関係4、生活5、お金3、地域活動3、挑戦4、プロダクト4、自己成長1。

品質基準:

- Mission候補が8〜10件である。
- すべてのMissionに観測可能な完了条件がある。
- Missionタイトルが重複しない。
- 分野固有の要素が2つ以上含まれる。
- 通信・生成エラーでユーザー体験が壊れない。
- Gemini生成かフォールバックかを区別して記録する。

## Safety Boundaries

- 医療診断、治療効果、金融利益、法律、入国条件、価格、運航情報を断定しない。
- 変わり得る情報は公式情報または専門家へ確認するMissionにする。
- 健康Questには休養・中止・相談条件を含める。
- 人間関係Questでは相手の同意と境界を優先する。
- 地域活動では安全、個人情報、会場規則を確認する。

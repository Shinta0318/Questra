# QST-250 Report: Gemini Structured Quest Output Contract

## Result

Completed. Added versioned schemas for Quest Understanding, Success Contract, Strategic Plan, Mission Plan, Critic, and Repair. Server validation rejects Quest mismatch, invalid ranges, duplicate IDs/titles, missing dependencies, cycles, generic Missions, and unverifiable completion conditions.

Schema-invalid or semantically invalid output cannot become an approvable Preview.

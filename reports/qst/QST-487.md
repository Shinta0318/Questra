# QST-487 Trail Journey Analytics Privacy Contract

## Goal

Trail作成導線の利用状況を改善へ活かしながら、旅の内容や親entityをAnalyticsへ持ち込まない。

## Implementation

- composer open、parent selection、Mission recovery、draft conflict resolution、save successの5イベントを追加した。
- 専用`trailJourney` helperはsurface、outcome、source、`has_quest`、`has_mission`だけを送る。
- user ID、Quest ID、Mission ID、Route ID、本文、title、summary、URLは設定しない。
- 既存allowlist sanitizerを通し、未知keyとblocked content keyを破棄する。
- すべてbest-effortの非同期記録とし、Analytics障害でTrail作成を止めない。

## External boundary

本QSTはイベント契約とlocal repository evidenceを対象とする。Hosted集計dashboard、retention、operator権限は既存Analytics運用QSTの外部証跡を必要とする。

# QST-491 Trail Parent Availability Feedback

## Goal

Trail composerを開いている間にQuest／Missionが更新されても、古い親階層へ保存を試みず利用者が回復できるようにする。

## Implementation

- 選択済みQuestがarchived／missingになった状態を検出する。
- 選択済みMissionがremoved／missing、または別Quest所属になった状態を検出する。
- 「もう一度選択してください」をlive regionとerror colorで表示する。
- stale IDはDropdownの現在値へ渡さず、再選択を要求する。
- 本文controllerとdraft IDは保持し、親の変化で入力を失わない。

## Evidence

- `apps/mobile/lib/features/trail/trail_screen.dart`
- `apps/mobile/test/qst_491_trail_parent_availability_feedback_test.dart`

## Validation

- Parent availability and domain validation regression: 5 tests passed.

## External boundary

Hosted DBの同時更新競合は最終保存時のRLS／FK／Repository errorでも拒否される必要がある。ローカルWidget testは二端末同時操作を代替しない。

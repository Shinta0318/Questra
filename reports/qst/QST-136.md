# QST-136 Report: Quest DNA Review Controls

## Summary

Added MVP-safe review controls for Quest DNA Snapshot. Users can now open a
review sheet from Quest detail, see which attributes are direct input versus
inferred context, and understand that inferred values are recalculated from
Quest input rather than separately persisted.

## Changed Files

- `apps/mobile/lib/features/quest/quest_detail_screen.dart`
- `apps/mobile/test/responsive_screen_smoke_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-136.md`

## Implementation Notes

- Added `Quest DNAを見直す` action to the snapshot section.
- Review sheet lists every DNA attribute with input/inferred source labels.
- Inferred values are explicitly described as `推定値・未保存`.
- Added a direct route to Quest editing so users can correct source input.

## Acceptance

- Quest DNA Snapshot has a visible review action.
- The review sheet explains inference transparency and non-persistence.
- Users can navigate to Quest editing from the review flow.
- Responsive smoke coverage verifies the review sheet copy.

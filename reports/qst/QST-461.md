# QST-461 Trail Journey Filter

## Goal

Trailが増えても、Quest→Missionの航路単位で記録をすぐ見返せるようにする。

## Implementation

- Trail上部へQuestとMissionの段階フィルターを追加した。
- Questを選ぶまでMission選択を無効化し、cross-parent候補を出さない。
- 選択Questに実際のTrailがあるMissionだけを候補にした。
- 絞り込み時はTrail件数、画像、ハイライト集計も表示対象へ合わせた。
- 解除操作を明示し、すべてのTrailへ一度で戻れるようにした。
- 560px未満は1カラム、それ以上は2カラムにして小画面overflowを避けた。

# QST-133 Report: Quest Theme Card Redesign

## Summary

Moved Quest card visual identity out of screen-local hardcoded styling and into
a reusable `QuestThemeResolver`. Quest cards now adapt their poster gradient,
icon, theme name, Quest DNA label, and Arc hint based on Quest category/title
signals.

## Changed Files

- `apps/mobile/lib/features/quest/quest_theme_card.dart`
- `apps/mobile/lib/features/quest/quest_screen.dart`
- `apps/mobile/test/quest_theme_card_test.dart`
- `docs/qst/BACKLOG.yaml`
- `docs/product/qst_backlog.md`
- `reports/qst/QST-133.md`

## Implementation Notes

- Added `QuestThemeCard` metadata for reusable card presentation.
- Added `QuestThemeResolver` with category/title/description keyword matching.
- Applied resolved gradients, poster icon, Arc hint, Quest DNA label, and theme
  name to Quest list cards.
- Kept the implementation local and incremental, without backend or architecture
  churn.

## Acceptance

- Quest cards no longer own all theme styling inline.
- Learning, active/health, builder/work, family/life, adventure/travel, and
  fallback themes are represented.
- New visible labels use Quest/Mission/Trail language and avoid Story.
- Unit tests cover key theme resolution paths.

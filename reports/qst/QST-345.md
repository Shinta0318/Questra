# QST-345 Unified Today Focus and Completion Loop

## Status

Implemented locally.

## Summary

Home and Quest Journey now use a shared Today Focus contract instead of each
screen deriving its own primary and secondary Task behavior. The contract keeps
the next action list, parent Quest/Mission context, Trail prompt, and Horizon
prompt together so the completion loop can be extended without screen-specific
wording drift.

## Acceptance Notes

- Primary Today Focus Task is selected by the existing dependency-aware focus
  selector.
- Secondary Tasks are capped at two, making the total visible focus set at most
  three.
- Home and Quest Journey both resolve focus through
  `QuestFocusSelectionService.selectTodayFocus`.
- Completion copy now uses the shared Trail prompt contract.
- Parent context formatting is centralized through the focus contract.
- Activation journey routing now returns explicitly from each stage branch.

## 2026-11-01 Server progress guard follow-up

- `202611010001_task_current_route_progress_guard.sql`を追加。Task状態が`in_progress`または`completed`へ変わる際、親Questがactive、親Missionがtodoかつroute_state activeであることをDB Triggerで検査する。親行はNOWAITで共有ロックし、別端末の航路変更と競合したら進捗更新を失敗させる。
- 既存の完了取り消し・航路復元が使うcompleted→pendingなどの遷移はこのTriggerの対象外にした。`rls_behavior.sql`へ停止Missionの開始/完了拒否、終了Questの完了拒否、現行航路での開始/完了成功と失敗時のVersion不変を追加した。

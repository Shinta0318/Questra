# QST-249 Report: Gemini Model Routing and Version Pinning

## Result

Completed. Added role-based routing for classifier, understanding, strategy, generation, critic, repair, and schema repair. Production routes use explicit Stable names; Preview is disabled unless an explicit environment flag is enabled. Latest and Experimental aliases cannot become the default route.

## Initial Stable Policy

- Strategic planning / generation / critic: `gemini-3.6-flash`
- Understanding / repair: `gemini-3.5-flash`
- Lightweight classification / schema repair: `gemini-3.5-flash-lite`

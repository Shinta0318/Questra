# QST-413 Settings Actionable Index and Truthful Capabilities

Status: **InProgress (local implementation verified, external evidence pending)**

## Summary

設定トップを、説明だけの「設定ガイド」から操作可能な設定索引へ変更した。索引の各行は、設定専用Deep Linkまたは既存のArc Memory、データ管理、フィードバックRouteへ一意に接続する。設定詳細は対象項目だけを表示し、戻る操作で索引へ復帰できる構造にした。

## Implemented

- `SETTINGS_ACTION_INDEX_V2`を追加し、新しい索引・詳細Route構成を既定で有効化した。
- 操作と演出、航路の条件、チュートリアル、プライバシー、目的別同意へ固有Deep Linkを追加した。
- Arc Memory、データ管理、フィードバックは既存の実在Routeへ接続した。
- 不明な設定Deep Linkへ、設定メニューへ戻る回復画面を追加した。
- Supabase未接続時のデータ管理状態を「端末内のみ」とし、接続済みの場合だけ「利用できます」と表示する。
- 利用者向けコピーから`RLS`、`所有者境界`、`Privateデータ`を除き、データ保護の説明へ変更した。
- チュートリアル再表示は状態更新後にHomeへ移動し、実際のoverlayが表示される導線にした。

# QST-140 Horizon Graph Readiness

## Summary

Horizon Next ChallengeにChallenge Graph Insightを接続し、進行中Questに明確なGraphギャップがある場合は、無理に次の挑戦を提案せず、今のQuestを強くする提案を返せるようにした。

## Implementation Notes

- `HorizonNextChallengeService.suggest`に任意引数`graphInsights`を追加した。
- 既存呼び出しとの互換性を保つため、デフォルトは空リストにしている。
- 進行中Questがあり、完了Questがまだない場合はGraph InsightをHorizon候補として返す。
- 完了Questがある高readinessの流れは維持している。
- HomeではQST-139で集めたGraph InsightをHorizonにも渡す。

## Acceptance

- HorizonがChallenge Graph Insightを受け取れる。
- Active QuestのGraphギャップがHorizon提案になる。
- 完了Questの勢いを使う既存挙動は維持される。
- Story表記は追加していない。
- ArcをAI assistantとして表現していない。

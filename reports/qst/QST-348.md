# QST-348 Cursor-Paginated Journey Data Plane

## Status

Implemented locally as a foundation.

## Summary

Added a reusable cursor pagination contract and keyset index migration for the
core journey data plane. This does not yet convert every repository, but it
establishes the shared page/request/cursor behavior and the database indexes
needed to migrate Quest, Mission, Task, Trail, Media, and Guild queries safely.

- `supabase/migrations/202608250001_journey_cursor_pagination_indexes.sql`

## Acceptance Notes

- Added `CursorPageRequest`, `CursorPage`, and `CursorPaginationService`.
- Added stable descending cursor helper based on `created_at + id`.
- Added journey page limits to the performance token catalog.
- Added keyset indexes for Quest, Mission, Task, Trail, Media, and Guild post
  traversal.
- Cursor tests cover 125 rows without gaps or duplicates.
- Oversized page requests are capped.
- Unknown cursors restart from the first page on the client contract; server
  repositories must still filter by owner and parent before applying cursor
  predicates.

# QST-135 Report: Quest DNA Snapshot

## Summary

Added an MVP-safe Quest DNA Snapshot on the Quest detail screen. The snapshot
uses existing Quest fields and theme metadata to show lightweight context for
category, theme, difficulty, duration, motivation, social type, and risk level.
It explicitly distinguishes user-entered values from inferred context, matching
the Master Spec rule that inference must be transparent and minimal.

## Implementation Notes

- Added `QuestDnaSnapshotResolver` with no backend/schema changes.
- Snapshot attributes identify their source as `入力` or `推定`.
- Inference is intentionally limited to existing Quest fields and avoids
  sensitive life-stage or enterprise assumptions.
- Quest detail now displays the snapshot below the journey overview.

## Acceptance

- Snapshot includes category, theme, difficulty, duration, motivation, social,
  and risk attributes.
- User input and inferred context are visibly distinguished.
- Quest detail renders the snapshot in responsive smoke coverage.
- Unit tests cover source labeling and risk inference.

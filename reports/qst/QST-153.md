# QST-153 Common UI Simplification

## Summary

主要5画面の背景とSafeAreaを`QuestraScreenSurface`へ統一した。
後続のGuild/Trail切替で使う`QuestraComingSoonScreen`も共通状態として追加した。

## Implementation Notes

- Home、Quest、Arc、Guild、Profileが同じadventure backgroundとSafeAreaを使う。
- 既存のResponsive ListView、Card、Primary Buttonは再利用した。
- Coming Soonは機能名、短い説明、Arc、状態表示、Homeへ戻る主要操作だけを持つ。
- 既存機能、Route、データ、Migrationは削除していない。
